# 04-复盘

每个 feature 收尾时在此目录写一份 RETRO，文件名 `<feature-name>-retro.md`。

## 用法

1. 复制 [_template.md](_template.md) 为 `<feature-name>-retro.md`
2. 按七段填实（Sprint 设置 / 最终结果 / What Worked / What Hurt / 合并冲突案例集 / Numbers / Action Items）
3. 提交进 master 时 commit message 引用本文件路径
4. 重复出现 ≥2 次的 Action Items 反哺到 [CLAUDE.md](../../CLAUDE.md)
