# UI/UX 优化记录 - 2026-06-09

## 概述

本次优化针对前端时间线页面的多个UI/UX问题进行了全面修复，主要解决移动端布局问题、下拉菜单定位问题以及文本对比度问题。

## 修复的问题

### P0-1: 胶囊导航文字竖排（文字换行）

**问题描述**: 移动端胶囊导航（概览、任务清单、疫苗接种、成长记录）文字出现竖排现象，影响用户体验。

**根本原因**: `TimelineLayout.vue` 中的 `.tab-text` 没有设置 `white-space: nowrap` 和 `overflow: hidden`，导致文字在空间不足时换行。

**修复方案**:
- **文件**: `frontend/src/views/Timeline/TimelineLayout.vue`
- **改动**:
  1. `.premium-tabs-container` 添加 `overflow-x: auto` 和 `scrollbar-width: none`
  2. `.tab-btn` 添加 `flex-shrink: 0` 和调整 `padding` 为 `10px 12px`
  3. `.tab-text` 添加 `white-space: nowrap`, `overflow: hidden`, `text-overflow: ellipsis`
  4. 移动端媒体查询：添加 `@media (max-width: 640px)` 样式

```css
.premium-tabs-container {
  overflow-x: auto;  /* 允许横向滚动 */
  scrollbar-width: none;  /* 隐藏滚动条 */
}

.tab-btn {
  flex-shrink: 0;  /* 防止收缩 */
  padding: 10px 12px;
}

.tab-text {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

@media (max-width: 640px) {
  .tab-btn {
    flex: 0 0 auto;
    padding: 10px 8px;
  }
  .tab-text {
    font-size: 12px;
  }
}
```

### P1-1: 页面宽度抖动

**问题描述**: 切换到"成长记录"标签时，页面整体宽度发生变化，导致页面抖动。

**根本原因**: 滚动条的出现/消失导致页面布局偏移。不同标签内容高度不同，导致滚动条状态变化。

**修复方案**:
- **文件**: `frontend/src/assets/styles/main.css`
- **改动**: 在 `:root` 添加 `scrollbar-gutter: stable`

```css
:root {
  scrollbar-gutter: stable; /* 预留滚动条空间，防止页面抖动 */
}
```

### P1-2: 下拉菜单被遮盖

```css

  z-index: 1000;  /* 从 998 提升 */
}

.filter-dropdown-menu,
.date-filter-dropdown {
  z-index: 1001;  /* 从 999 提升 */
}
```

### P1-3: 下拉菜单左侧溢出

**问题描述**: 点击"全部记录"按钮后，下拉菜单左边缘超出容器边界。

**根本原因**: 下拉菜单仅使用 `right` 定位，未检测左侧溢出情况。

**修复方案**:
- **文件**: `frontend/src/views/Timeline/GrowthRecords.vue`
- **改动**: 在 `filterDropdownStyle` 和 `dateDropdownStyle` 中添加左侧溢出检测逻辑

```typescript
const filterDropdownStyle = computed(() => {
  if (!filterTriggerRef.value) return {}
  const rect = filterTriggerRef.value.getBoundingClientRect()
  const menuWidth = 280
  const wouldOverflow = rect.left < menuWidth  // 检测左侧溢出

  return {
    position: 'fixed',
    top: `${rect.bottom + 8}px`,
    right: wouldOverflow ? '16px' : `${window.innerWidth - rect.right}px`,
    left: wouldOverflow ? '16px' : 'auto',  // 溢出时使用 left 定位
    zIndex: 1001
  }
})
```

同时添加 `max-width: calc(100vw - 32px)` 防止溢出：

```css
.filter-dropdown-menu {
  max-width: calc(100vw - 32px);
}
```

### P1-4: 下拉菜单底部被截断

**问题描述**: 点击"全部记录"或"全部日期"按钮后，下拉菜单底部显示不全。

**根本原因**: 下拉菜单始终定位在按钮下方（`top: ${rect.bottom + 8}px`），未检测底部空间是否足够。

**修复方案**:
- **文件**: `frontend/src/views/Timeline/GrowthRecords.vue`
- **改动**: 添加垂直位置检测，当底部空间不足时将菜单定位到按钮上方

```typescript
const filterDropdownStyle = computed(() => {
  if (!filterTriggerRef.value) return {}
  const rect = filterTriggerRef.value.getBoundingClientRect()
  const menuWidth = 280
  const wouldOverflow = rect.left < menuWidth

  // 计算垂直位置 - 检测菜单是否会超出视口底部
  const spaceBelow = window.innerHeight - rect.bottom
  const menuHeight = 300  // 预估菜单高度
  const shouldPositionAbove = spaceBelow < menuHeight + 16  // 16px 安全边距

  return {
    position: 'fixed',
    top: shouldPositionAbove ? 'auto' : `${rect.bottom + 8}px`,
    bottom: shouldPositionAbove ? `${window.innerHeight - rect.top + 8}px` : 'auto',
    right: wouldOverflow ? '16px' : `${window.innerWidth - rect.right}px`,
    left: wouldOverflow ? '16px' : 'auto',
    zIndex: 1001
  }
})

const dateDropdownStyle = computed(() => {
  if (!dateFilterTriggerRef.value) return {}
  const rect = dateFilterTriggerRef.value.getBoundingClientRect()
  const menuWidth = 320
  const wouldOverflow = rect.left < menuWidth

  // 日期选择器更高，使用更大的预估高度
  const spaceBelow = window.innerHeight - rect.bottom
  const menuHeight = 360
  const shouldPositionAbove = spaceBelow < menuHeight + 16

  return {
    position: 'fixed',
    top: shouldPositionAbove ? 'auto' : `${rect.bottom + 8}px`,
    bottom: shouldPositionAbove ? `${window.innerHeight - rect.top + 8}px` : 'auto',
    right: wouldOverflow ? '16px' : `${window.innerWidth - rect.right}px`,
    left: wouldOverflow ? '16px' : 'auto',
    zIndex: 1001
  }
})
```

## 技术要点

### Flexbox 弹性布局
- `flex-wrap: wrap` - 允许子元素换行
- `flex-shrink: 0` - 防止子元素收缩
- `white-space: nowrap` - 防止文字换行

### CSS 定位
- `position: fixed` - 固定定位，相对于视口
- `getBoundingClientRect()` - 获取元素相对于视口的位置
- 动态计算 `top`/`bottom`/`left`/`right` 实现智能定位

### CSS Z-index 层级
- 模态遮罩层: 1000
- 下拉菜单: 1001
- 确保菜单始终在遮罩层之上

### 移动端响应式设计
- `@media (max-width: 640px)` - 移动端断点
- 使用相对单位（rem）而非固定像素
- 减小字体、间距、元素尺寸以适应小屏幕

### CSS 滚动条优化
- `scrollbar-gutter: stable` - 预留滚动条空间，防止布局偏移
- `scrollbar-width: none` - 隐藏滚动条（Firefox）
- `::-webkit-scrollbar { display: none; }` - 隐藏滚动条（Chrome/Safari）
