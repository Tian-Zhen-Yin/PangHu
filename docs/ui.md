# 🎨 一、整体视觉设定

### 🌈 色彩系统

* 页面背景：#FFF8F3（奶油底）
* 主色：#FF8FA3（柔粉）
* 辅助色：#FFD6A5（奶橙）
* 点缀色：#95D5B2（薄荷绿）
* 主文字：#5F4B4B
* 次文字：#9B8B8B

### 🟡 阴影

暖色阴影：

```
0 10px 30px rgba(255, 180, 162, 0.15)
```

不是灰色阴影。
