# 胖虎吉祥物视觉系统开发文档

> **版本:** v2.1 (视觉高光破形版)
> **更新时间:** 2026-03-01
> **作者:** yintao24 (yintao24@yonyou.com)
> **核心设计理念:** 从“全局悬浮挂件”升级为“UI组件的灵魂”。拒绝突兀的遮挡，利用“破形”与“色彩衬托”建立界面视觉焦点。

## 概述

胖虎是「哈吉咪」App 的核心情感枢纽。本规范旨在指导开发者如何将扁平化风格的胖虎插画，以**内联嵌入（Inline-embedding）**、**场景化（Scenario-driven）**以及**破形高光（Breakout Effect）**的方式融入界面，消除视觉割裂感，打造极简、温馨且极具视觉焦点的奶油风使用体验。

## 二、 核心集成范式 (Anti-Sticker 布局)

### 🚫 反模式 (避免使用)

* **巨大的右下角悬浮窗**：遮挡列表内容，产生“外挂贴纸”的廉价感。
* **顺色平铺**：将浅灰色插画直接放在纯白或米白底色上，导致缺乏视觉焦点。

### 2.5 成长趋势可视化 (Weight Trend Sparkline)

在“最近记录”列表顶部嵌入一个极简的体重波动趋势图。通过平滑的曲线和渐变填充，让用户一眼感知猫咪的成长速度。

**组件路径:** `src/components/record/WeightSparkline.vue`

```vue
<template>
  <div class="sparkline-card">
    <div class="chart-header">
      <div class="title-group">
        <MascotCharacter expression="excited" size="xs" :animated="false" />
        <span class="label">体重成长趋势</span>
      </div>
      <span class="current-val">{{ latestWeight }}kg</span>
    </div>
    
    <div class="svg-container">
      <svg :viewBox="`0 0 ${width} ${height}`" preserveAspectRatio="none">
        <defs>
          <linearGradient id="gradient" x1="0" y1="0" x2="0" y2="1">
            <stop offset="0%" stop-color="var(--color-primary)" stop-opacity="0.2" />
            <stop offset="100%" stop-color="var(--color-primary)" stop-opacity="0" />
          </linearGradient>
        </defs>
        
        <path :d="areaPath" fill="url(#gradient)" />
        <path :d="linePath" fill="none" stroke="var(--color-primary)" stroke-width="3" stroke-linecap="round" stroke-linejoin="round" />
        
        <circle :cx="lastPoint.x" :cy="lastPoint.y" r="4" fill="var(--color-primary)" stroke="#fff" stroke-width="2" />
      </svg>
    </div>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue';
import MascotCharacter from '@/components/mascot/MascotCharacter.vue';

interface DataPoint {
  weight: number;
  date: string;
}

const props = defineProps<{
  data: DataPoint[];
}>();

const width = 300;
const height = 80;
const padding = 10;

const latestWeight = computed(() => props.data[props.data.length - 1]?.weight || 0);

// 将体重数据映射到 SVG 坐标系
const points = computed(() => {
  if (props.data.length < 2) return [];
  const minW = Math.min(...props.data.map(d => d.weight)) * 0.9;
  const maxW = Math.max(...props.data.map(d => d.weight)) * 1.1;
  const range = maxW - minW;

  return props.data.map((d, i) => ({
    x: (i / (props.data.length - 1)) * (width - padding * 2) + padding,
    y: height - ((d.weight - minW) / range) * (height - padding * 2) - padding
  }));
});

// 生成 SVG 路径指令 (使用二次贝塞尔曲线平滑)
const linePath = computed(() => {
  if (points.value.length < 2) return '';
  return points.value.reduce((path, p, i) => {
    return i === 0 ? `M ${p.x} ${p.y}` : `${path} L ${p.x} ${p.y}`; // 这里可优化为 C 曲线
  }, '');
});

const areaPath = computed(() => {
  if (points.value.length < 2) return '';
  return `${linePath.value} L ${points.value[points.value.length - 1].x} ${height} L ${points.value[0].x} ${height} Z`;
});

const lastPoint = computed(() => points.value[points.value.length - 1] || { x: 0, y: 0 });
</script>

<style scoped>
.sparkline-card {
  background: var(--color-card-bg);
  border-radius: 20px;
  padding: 16px;
  margin: 0 20px 16px;
  box-shadow: var(--shadow-sm);
}
.chart-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  margin-bottom: 12px;
}
.title-group {
  display: flex;
  align-items: center;
  gap: 6px;
  font-size: 14px;
  font-weight: 600;
  color: var(--color-text-main);
}
.current-val {
  font-size: 18px;
  font-weight: 700;
  color: var(--color-primary);
}
.svg-container {
  height: 80px;
  width: 100%;
}
svg {
  width: 100%;
  height: 100%;
  overflow: visible;
}
</style>

```

### 3.2 交互微动效 (Micro-interactions)

放弃夸张的全局上下浮动，转为**由用户行为触发**的即时反馈：

## 四、 MascotCharacter 组件 API

为适应内联布局与破形需求，对组件属性进行扩充：

**Props**
| 参数 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `expression` | `MascotExpression` | `'default'` | 控制显示的猫咪神态 |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 增加 xs(24px) 适应内联文本，sm(48px) 适应按钮 |
| `layout` | `'inline' \| 'block' \| 'float'` | `'inline'` | **强烈建议默认 `inline**`。使用 CSS 控制大小实现破形效果。 |
| `animated` | `boolean` | `false` | 默认关闭，仅在 Loading 或强调场景开启，避免过度分散注意力 |

## 五、 资产管理与加载策略

* **按需预加载**: `default`, `waiting`, `excited`, `focused` 作为首页核心资产，需在应用初始化时优先预加载，防止视觉破形区闪烁。
* **懒加载**: `sleepy`, `confused` 等非首屏状态图，采用动态 import 进行懒加载，优化首屏性能。
