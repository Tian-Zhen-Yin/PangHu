# 快速开始指南

> **版本:** V4.0
> **更新时间:** 2026-06-04

本指南将帮助你在 10 分钟内搭建好哈吉咪养成计划的开发环境。

---

## 📋 前置要求

在开始之前，请确保你的开发环境满足以下要求：

### 必需工具

- **Node.js** >= 18.x ([下载地址](https://nodejs.org/))
- **npm** >= 9.x 或 **yarn** >= 1.22.x
- **Git** >= 2.x ([下载地址](https://git-scm.com/))
- **代码编辑器** (推荐 VS Code)

### 可选工具

- **PostgreSQL** >= 14.x (生产环境数据库)
- **Docker** (容器化部署)

### 检查环境

```bash
# 检查 Node.js 版本
node --version

# 检查 npm 版本
npm --version

# 检查 Git 版本
git --version
```

## 🚀 快速安装

### 1. 克隆项目

```bash
# 克隆仓库
git clone https://github.com/Tian-Zhen-Yin/PangHu.git

# 进入项目目录
cd PangHu
```

### 2. 后端安装

```bash
# 进入后端目录
cd backend

# 安装依赖
npm install

# 生成 Prisma 客户端
npm run db:generate

# 推送数据库 schema
npm run db:push

# 生成测试数据（可选）
npm run db:test-data

# 返回项目根目录
cd ..
```

### 3. 前端安装

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 返回项目根目录
cd ..
```

---

## ⚙️ 环境配置

### 后端配置

创建 `backend/.env` 文件：

```bash
# 服务器配置
PORT=3000

# 数据库配置
DATABASE_URL="file:./prisma/dev.db"

# JWT 配置
JWT_SECRET=your_jwt_secret_key_here
JWT_EXPIRES_IN=7d

# 智谱 AI 配置
ZHIPUAI_API_KEY=your_zhipuai_api_key_here
ZHIPUAI_MODEL=glm-4-flash
```

### 前端配置

创建 `frontend/.env` 文件：

```bash
# API 基础 URL
VITE_API_BASE_URL=http://localhost:3000/api
```

## 🏃 启动项目

### 开发模式启动

**终端 1 - 启动后端：**

```bash
cd backend
npm run dev
```

**终端 2 - 启动前端：**

```bash
cd frontend
npm run dev
```

### 访问应用

- **前端地址**: http://localhost:5173
- **后端地址**: http://localhost:3000
- **API 文档**: http://localhost:3000/api/docs (如已配置)

## 🔧 常见问题

### 问题 1：端口被占用

**错误信息：** `Error: listen EADDRINUSE: address already in use`

**解决方案：**

```bash
# 查找占用端口的进程
# Windows
netstat -ano | findstr :3000

# macOS/Linux
lsof -i :3000

# 结束进程或更改 .env 中的 PORT
```

### 问题 2：数据库连接失败

**错误信息：** `Error connecting to database`

**解决方案：**

```bash
# 重新生成 Prisma 客户端
cd backend
npm run db:generate

# 重新推送 schema
npm run db:push
```

### 问题 3：前端无法连接后端

**检查清单：**

1. 后端是否正常运行（访问 http://localhost:3000）
2. 前端 `.env` 中的 `VITE_API_BASE_URL` 是否正确
3. 浏览器控制台是否有 CORS 错误
