## 🛠️ 技术栈总览

### 前端
- **框架**: Vue 3 (Composition API) + TypeScript
- **构建**: Vite
- **状态**: Pinia + pinia-plugin-persistedstate
- **路由**: Vue Router
- **UI**: Element Plus
- **图表**: ECharts 5.x
- **HTTP**: Axios

### 后端
- **运行时**: Node.js
- **框架**: Express + TypeScript
- **数据库**: SQLite (开发) / PostgreSQL (生产)
- **ORM**: Prisma
- **认证**: JWT
- **AI**: 智谱 AI GLM-4-flash
- **流式**: SSE
