## 🔧 环境问题

### 问题 1：Node.js 版本不兼容

**症状：**

```bash
Error: The module was compiled against a different Node.js version
```

**诊断：**

```bash
# 检查当前版本
node --version

# 检查 package.json 要求
cat package.json | grep engines
```

**解决方案：**

```bash
# 方案一：升级 Node.js
# 使用 nvm（推荐）
nvm install 18
nvm use 18

# 方案二：使用 n
npm install -g n
n 18

# 方案三：从官网下载
# 访问 https://nodejs.org/
```

### 问题 2：依赖安装失败

**症状：**

```bash
npm ERR! code ERESOLVE
npm ERR! ERESOLVE unable to resolve dependency tree
```

**诊断：**

```bash
# 清除缓存
npm cache clean --force

# 检查网络
ping registry.npmjs.org
```

**解决方案：**

```bash
# 方案一：使用 --legacy-peer-deps
npm install --legacy-peer-deps

# 方案二：使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install

# 方案三：删除 node_modules 重新安装
rm -rf node_modules package-lock.json
npm install
```

## 🗄️ 数据库问题

### 问题 3：数据库连接失败

**症状：**

```bash
Error: Can't reach database server at `localhost:5432`
```

**诊断：**

```bash
# 检查 SQLite
cd backend
ls -la prisma/dev.db

# 检查 PostgreSQL
pg_isready -h localhost -p 5432
```

**解决方案：**

```bash
# SQLite 方案
cd backend
npx prisma generate
npx prisma db push

# PostgreSQL 方案
# 启动 PostgreSQL 服务
sudo systemctl start postgresql

# 检查连接
psql -U postgres -h localhost
```

### 问题 4：Prisma 迁移错误

**症状：**

```bash
Error: P3006
Migration failed to apply cleanly
```

**诊断：**

```bash
# 检查迁移状态
npx prisma migrate status

# 重置数据库（开发环境）
npx prisma migrate reset --force
```

**解决方案：**

```bash
# 方案一：重新生成客户端
npx prisma generate

# 方案二：强制推送（会删除数据）
npx prisma db push --force-reset

# 方案三：手动解决冲突
npx prisma migrate resolve --applied "migration_name"
```

## 🌐 API 问题

### 问题 5：401 未授权错误

**症状：**

```json
{
  "success": false,
  "message": "未提供认证令牌"
}
```

**诊断：**

```javascript
// 浏览器控制台
console.log(localStorage.getItem('auth_token'))

// 检查请求头
// Network Tab → Request Headers → Authorization
```

**解决方案：**

```javascript
// 前端：检查 Token 存储
const token = localStorage.getItem('auth_token')
if (!token) {
  // 重新登录
  router.push('/login')
}

// 前端：确保请求携带 Token
api.defaults.headers.common['Authorization'] = `Bearer ${token}`
```

### 问题 6：403 禁止访问错误

**症状：**

```json
{
  "success": false,
  "message": "无权访问该资源"
}
```

**诊断：**

```bash
# 检查用户权限
# 后端日志中查看 userId 和资源 owner
```

**解决方案：**

```typescript
// 后端：检查权限验证
export async function getCat(req: Request, res: Response) {
  const userId = (req as any).user?.userId
  const catId = req.params.id

  // 验证资源所有权
  const cat = await prisma.cat.findFirst({
    where: { id: catId, userId } // 确保用户只能访问自己的猫咪
  })

  if (!cat) {
    return res.status(403).json(errorResponse('无权访问该资源'))
  }
}
```

### 问题 7：404 资源不存在错误

**症状：**

```json
{
  "success": false,
  "message": "猫咪不存在"
}
```

**诊断：**

```bash
# 检查数据库
npx prisma studio

# 查看该 ID 的记录是否存在
```

**解决方案：**

```typescript
// 前端：验证资源存在性
async function fetchCatDetail(catId: string) {
  try {
    const response = await getCatDetail(catId)
    if (!response.success) {
      // 资源不存在，跳转回列表
      router.push('/my-cats')
      return
    }
    return response.data
  } catch (error) {
    console.error('获取猫咪详情失败', error)
  }
}
```

### 问题 8：500 服务器内部错误

**症状：**

```json
{
  "success": false,
  "message": "服务器内部错误"
}
```

**诊断：**

```bash
# 查看后端日志
cd backend
npm run dev

# 查看具体错误堆栈
```

**解决方案：**

```typescript
// 后端：添加错误处理
export async function someFunction(req: Request, res: Response, next: NextFunction) {
  try {
    // 业务逻辑
  } catch (error: any) {
    console.error('[Function] Error:', error)

    // 开发环境返回详细错误
    if (process.env.NODE_ENV === 'development') {
      return res.status(500).json({
        success: false,
        message: error.message,
        stack: error.stack
      })
    }

    // 生产环境返回通用错误
    res.status(500).json(errorResponse('服务器内部错误'))
  }
}
```

```bash
rm -rf frontend/node_modules
rm -rf frontend/dist
npm install

# 方案三：检查路由配置
# 确保服务器配置了 fallback
```

### 问题 10：路由 404 错误

**症状：**

刷新页面后显示 404 Not Found。

**诊断：**

```bash
# 检查服务器配置
# 对于 SPA，需要配置 fallback
```

**解决方案：**

```nginx
# Nginx 配置
location / {
    try_files $uri $uri/ /index.html;
}
```

```javascript
// Vercel 配置
// vercel.json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```
