## 📊 核心模型

### User（用户）

用户账号信息，支持邮箱登录。

```prisma
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  password  String
  username  String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  // 关联
  cats      Cat[]
}
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | PRIMARY KEY | 用户唯一标识 |
| email | String | UNIQUE, NOT NULL | 登录邮箱 |
| password | String | NOT NULL | 加密后的密码 |
| username | String | OPTIONAL | 显示名称 |
| createdAt | DateTime | DEFAULT NOW() | 创建时间 |
| updatedAt | DateTime | UPDATED AT | 更新时间 |

---

### Cat（猫咪）

用户添加的猫咪信息。

```prisma
model Cat {
  id          String   @id @default(cuid())
  name        String
  breed       String?
  gender      String
  birthDate   DateTime
  weight      Float?
  avatar      String?
  userId      String
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  // 关联
  user        User         @relation(fields: [userId], references: [id])
  records     PetRecord[]
  vaccines    VaccineRecord[]

  // 索引
  @@index([userId])
  @@index([isActive])
}
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | PRIMARY KEY | 猫咪唯一标识 |
| name | String | NOT NULL | 猫咪名称 |
| breed | String | OPTIONAL | 品种 |
| gender | String | NOT NULL | 性别：male/female |
| birthDate | DateTime | NOT NULL | 出生日期 |
| weight | Float | OPTIONAL | 当前体重（kg） |
| avatar | String | OPTIONAL | 头像URL |
| userId | String | FOREIGN KEY | 所属用户 |
| isActive | Boolean | DEFAULT true | 是否激活（软删除） |
| createdAt | DateTime | DEFAULT NOW() | 创建时间 |
| updatedAt | DateTime | UPDATED AT | 更新时间 |

---

### PetRecord（成长记录）

猫咪的成长记录，包括体重、照片等。

```prisma
model PetRecord {
  id          String   @id @default(cuid())
  catId       String
  recordDate  DateTime
  weight      Float?
  notes       String?
  photoUrl    String?
  ageWeeks    Int?
  ageMonths   Int?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  // 关联
  cat         Cat      @relation(fields: [catId], references: [id])

  // 索引
  @@index([catId])
  @@index([recordDate])
}
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | PRIMARY KEY | 记录唯一标识 |
| catId | String | FOREIGN KEY | 关联的猫咪 |
| recordDate | DateTime | NOT NULL | 记录日期 |
| weight | Float | OPTIONAL | 体重（kg） |
| notes | String | OPTIONAL | 备注信息 |
| photoUrl | String | OPTIONAL | 照片URL |
| ageWeeks | Int | OPTIONAL | 年龄（周） |
| ageMonths | Int | OPTIONAL | 年龄（月） |
| createdAt | DateTime | DEFAULT NOW() | 创建时间 |
| updatedAt | DateTime | UPDATED AT | 更新时间 |

---

### VaccineRecord（疫苗记录）

猫咪的疫苗接种记录。

```prisma
model VaccineRecord {
  id              String   @id @default(cuid())
  catId           String
  vaccineName     String
  vaccineDate     DateTime
  nextVaccineDate DateTime?
  notes           String?
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt

  // 关联
  cat             Cat      @relation(fields: [catId], references: [id])

  // 索引
  @@index([catId])
  @@index([vaccineDate])
}
```

**字段说明：**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | String | PRIMARY KEY | 记录唯一标识 |
| catId | String | FOREIGN KEY | 关联的猫咪 |
| vaccineName | String | NOT NULL | 疫苗名称 |
| vaccineDate | DateTime | NOT NULL | 接种日期 |
| nextVaccineDate | DateTime | OPTIONAL | 下次接种日期 |
| notes | String | OPTIONAL | 备注信息 |
| createdAt | DateTime | DEFAULT NOW() | 创建时间 |
| updatedAt | DateTime | UPDATED AT | 更新时间 |

## 🔄 数据迁移

### 开发环境迁移

```bash
# 生成 Prisma 客户端
npm run db:generate

# 推送 schema 到数据库
npm run db:push

# 重置数据库（会删除所有数据）
npm run db:push --force-reset
```

### 生产环境迁移

```bash
# 创建迁移
npx prisma migrate dev --name init

# 应用迁移
npx prisma migrate deploy

# 查看迁移状态
npx prisma migrate status
```

### 种子数据

```bash
# 生成测试数据
npm run db:test-data
```

## 🛠️ 常用操作

### 查询用户的所有猫咪

```typescript
const cats = await prisma.cat.findMany({
  where: {
    userId: userId,
    isActive: true
  },
  orderBy: {
    createdAt: 'desc'
  }
})
```

### 查询猫咪的成长记录

```typescript
const records = await prisma.petRecord.findMany({
  where: {
    catId: catId
  },
  orderBy: {
    recordDate: 'desc'
  },
  take: 20 // 限制返回数量
})
```

### 创建成长记录

```typescript
const record = await prisma.petRecord.create({
  data: {
    catId,
    recordDate: new Date(),
    weight: 1.5,
    notes: '健康成长中'
  }
})
```

### 软删除猫咪

```typescript
const cat = await prisma.cat.update({
  where: { id: catId },
  data: { isActive: false }
})
```
