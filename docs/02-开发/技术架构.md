## 🔄 数据流

### 认证流程

```
用户登录
   ↓
前端：发送登录请求
   ↓
后端：验证用户凭证
   ↓
后端：生成 JWT Token
   ↓
后端：返回 Token 和用户信息
   ↓
前端：存储 Token 到 localStorage
   ↓
前端：后续请求携带 Token
   ↓
后端：验证 Token 有效性
   ↓
后端：处理请求并返回结果
```

### AI 问答流程

```
用户提问
   ↓
前端：发送问题到后端
   ↓
后端：验证用户身份
   ↓
后端：调用 RAG 服务
   ↓
RAG：向量化用户问题
   ↓
RAG：检索相关知识片段
   ↓
AI：调用智谱 AI API
   ↓
AI：流式返回回答
   ↓
前端：实时显示回答
```

## 🗄️ 数据库设计

### 核心模型

#### User（用户）

```prisma
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  password  String
  username  String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  cats      Cat[]
}
```

#### Cat（猫咪）

```prisma
model Cat {
  id          String   @id @default(cuid())
  name        String
  breed       String?
  gender      String
  birthDate   DateTime
  weight      Float?
  avatar      String?
  userId      String
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  user        User     @relation(fields: [userId], references: [id])
  records     PetRecord[]
  vaccines    VaccineRecord[]
}
```

#### PetRecord（成长记录）

```prisma
model PetRecord {
  id          String   @id @default(cuid())
  catId       String
  recordDate  DateTime
  weight      Float?
  notes       String?
  photoUrl    String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  cat         Cat      @relation(fields: [catId], references: [id])
}
```

## 🔐 安全架构

### 认证机制

1. **JWT 认证**
   - 用户登录后返回 JWT Token
   - Token 有效期 7 天
   - Token 存储在 localStorage

2. **密码加密**
   - 使用 bcrypt 加密
   - 盐值自动生成
   - 不存储明文密码

3. **请求验证**
   - 所有 API 请求验证 Token
   - 过期 Token 自动刷新
   - 无效请求返回 401

### 数据安全

1. **用户隔离**
   - 所有数据查询关联 userId
   - 禁止跨用户数据访问
   - 软删除机制

2. **输入验证**
   - 使用 express-validator 验证输入
   - 防止 SQL 注入
   - XSS 防护
