## 📋 功能概述

体重趋势图表为每只猫咪提供可视化的体重变化记录，帮助用户：
- 查看体重变化趋势
- 监控生长发育情况
- 发现异常变化
- 对比标准范围

## 🏗️ 技术实现

### 前端组件

#### WeightTrend.vue（体重趋势图表）

**文件路径：** `frontend/src/components/cat/WeightTrend.vue`

**核心实现：**

```vue
<template>
  <div class="weight-trend">
    <div class="trend-header">
      <h3>体重趋势</h3>
      <span v-if="latestWeight" class="current-weight">
        当前体重: <strong>{{ latestWeight }}kg</strong>
      </span>
    </div>

    <!-- 加载状态 -->
    <div v-if="loading" class="loading">
      <LoadingSpinner />
    </div>

    <!-- 错误状态 -->
    <div v-else-if="error" class="error">
      <p>{{ error }}</p>
    </div>

    <!-- 空数据状态 -->
    <div v-else-if="weightHistory.length === 0" class="empty-state">
      <p>暂无体重记录</p>
      <p class="hint">添加成长记录时记录体重，即可查看趋势图</p>
    </div>

    <!-- 图表容器 -->
    <div v-else ref="chartRef" class="chart-container"></div>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted, onUnmounted, watch, nextTick } from 'vue'
import * as echarts from 'echarts'
import type { EChartsOption } from 'echarts'

interface Props {
  catId: string
  catName?: string
}

const props = defineProps<Props>()

// 状态
const chartRef = ref<HTMLDivElement>()
const weightHistory = ref<WeightHistoryRecord[]>([])
const loading = ref(true)
const error = ref('')
let chart: echarts.ECharts | null = null

// 计算最新体重
const latestWeight = computed(() => {
  if (weightHistory.value.length === 0) return null
  return weightHistory.value[weightHistory.value.length - 1]?.weight.toFixed(1)
})

// 初始化图表
function initChart() {
  if (!chartRef.value) return

  // 销毁已存在的图表
  if (chart) {
    chart.dispose()
  }

  chart = echarts.init(chartRef.value)
  updateChart()
}

// 更新图表数据
function updateChart() {
  if (!chart || weightHistory.value.length === 0) return

  const dates = weightHistory.value.map(r => r.date)
  const weights = weightHistory.value.map(r => r.weight)

  const option: EChartsOption = {
    title: {
      text: `${props.catName || '猫咪'}体重趋势`,
      left: 'center'
    },
    tooltip: {
      trigger: 'axis',
      formatter: (params: any) => {
        const param = params[0]
        return `${param.axisValue}<br/>体重: ${param.value}kg`
      }
    },
    xAxis: {
      type: 'category',
      data: dates,
      name: '日期'
    },
    yAxis: {
      type: 'value',
      name: '体重 (kg)',
      scale: true
    },
    series: [{
      name: '体重',
      type: 'line',
      smooth: true,
      data: weights,
      itemStyle: { color: '#f5a623' },
      areaStyle: {
        color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [{
          offset: 0,
          color: 'rgba(245, 166, 35, 0.3)'
        }, {
          offset: 1,
          color: 'rgba(245, 166, 35, 0.05)'
        }])
      },
      markPoint: {
        data: weightHistory.value.map((item, index) => ({
          name: item.notes || '记录',
          value: item.weight,
          xAxis: index,
          yAxis: item.weight
        }))
      }
    }]
  }

  chart.setOption(option)
}

// 获取体重历史数据
async function fetchWeightHistory() {
  loading.value = true
  error.value = ''

  try {
    const response = await getWeightHistory(props.catId)
    weightHistory.value = response.data || []

    // V3 关键修复：先关闭 loading，再等待 DOM 更新
    loading.value = false
    await nextTick()
    initChart()
  } catch (err: any) {
    error.value = err.message || '获取体重历史失败'
    loading.value = false
  }
}

// 窗口大小变化时重新渲染
function handleResize() {
  chart?.resize()
}

onMounted(() => {
  fetchWeightHistory()
  window.addEventListener('resize', handleResize)
})

onUnmounted(() => {
  chart?.dispose()
  window.removeEventListener('resize', handleResize)
})

// 监听 catId 变化
watch(() => props.catId, () => {
  fetchWeightHistory()
})
</script>
```

### 后端 API

#### 获取体重历史

**文件路径：** `backend/src/controllers/cats.controller.ts`

```typescript
export async function getWeightHistory(req: Request, res: Response) {
  try {
    const userId = (req as any).user?.userId
    const id = req.params.id as string

    // 调试日志
    console.log('[getWeightHistory] Request - userId:', userId, 'catId:', id)

    const history = await getCatWeightHistory(id, userId)

    console.log('[getWeightHistory] Result - records count:', history?.length || 0)

    if (!history) return res.status(404).json(errorResponse('猫咪不存在'))
    res.json(successResponse(history, '获取体重历史成功'))
  } catch (error: any) {
    console.error('[getWeightHistory] Error:', error)
    res.status(500).json(errorResponse(error.message || '获取体重历史失败'))
  }
}
```

#### 数据服务

**文件路径：** `backend/src/services/cat.service.ts`

```typescript
// 获取猫咪体重历史记录（用于趋势图）
export async function getCatWeightHistory(
  catId: string,
  userId: string
) {
  // 1. 验证猫咪存在且属于用户
  const cat = await prisma.cat.findFirst({
    where: { id: catId, userId, isActive: true }
  })

  if (!cat) return null

  // 2. 获取所有成长记录
  const allRecords = await prisma.petRecord.findMany({
    where: { catId },
    orderBy: { recordDate: 'asc' }
  })

  // 3. 过滤有体重的记录
  const records = allRecords
    .filter(r => r.weight !== null && r.weight !== undefined)
    .map(record => ({
      date: record.recordDate.toISOString().split('T')[0],
      weight: record.weight!,
      notes: record.notes
    }))

  // 4. 如果猫咪档案有初始体重，且没有更早记录，添加初始点
  if (cat.weight) {
    const hasEarlierRecord = records.length > 0 &&
      new Date(records[0].date) <= cat.createdAt

    if (!hasEarlierRecord) {
      records.unshift({
        date: cat.createdAt.toISOString().split('T')[0],
        weight: cat.weight,
        notes: '初始体重'
      })
    }
  }

  return records
}
```

## 🐛 常见问题

### 问题 1：图表不显示

**症状：** 图表区域为空白

**解决方案：**

1. 检查是否有体重记录
2. 查看浏览器控制台错误
3. 确认 ECharts 已正确加载

**调试步骤：**

```javascript
// 检查数据
console.log('[WeightTrend] weightHistory:', weightHistory.value)
console.log('[WeightTrend] chartRef:', chartRef.value)

// 检查容器尺寸
console.log('[WeightTrend] container size:', chartRef.value?.getBoundingClientRect())
```

### 问题 2：时序问题

**症状：** 数据加载但图表不初始化

**原因：** 在 `loading.value = false` 之前调用 `initChart()`

**解决方案：**

```typescript
// ❌ 错误顺序
try {
  weightHistory.value = response.data
  await nextTick()
  initChart()  // 此时 loading 还是 true！
} finally {
  loading.value = false
}

// ✅ 正确顺序
try {
  weightHistory.value = response.data
  loading.value = false  // 先关闭 loading
  await nextTick()       // 等待 DOM 更新
  initChart()            // 现在 chartRef 存在了
} catch (err) {
  loading.value = false
}
```

### 问题 3：图表尺寸异常

**症状：** 图表宽度或高度为 0

**解决方案：**

```typescript
function initChart() {
  if (!chartRef.value) return

  // 检查容器尺寸
  const rect = chartRef.value.getBoundingClientRect()
  if (rect.width === 0 || rect.height === 0) {
    // 延迟重试
    setTimeout(() => {
      if (chartRef.value) initChart()
    }, 100)
    return
  }

  chart = echarts.init(chartRef.value)
  updateChart()
}
```

## 💡 使用建议

### 最佳实践

1. **定期记录**
   - 建议每月记录一次
   - 使用固定日期（如每月1号）
   - 保持连续性

2. **数据质量**
   - 确保体重单位正确（kg）
   - 添加有意义的备注
   - 使用标准日期格式

3. **趋势分析**
   - 关注整体趋势而非单点数据
   - 考虑季节性变化
   - 对比同龄猫咪标准
