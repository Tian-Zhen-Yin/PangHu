# 体重健康标准系统

> **功能版本:** V3.1
> **更新时间:** 2026-06-04
> **功能状态:** ✅ 已上线

本文档详细描述体重健康标准系统的实现细节和使用说明。

---

## 📋 功能概述

体重健康标准系统为每只猫咪提供个性化的体重健康分析，包括：
- 品种标准体重范围
- 当前体重健康状态判断
- 体重偏差分析
- 体重趋势建议

---

## 🎯 功能特性

### 核心功能

| 功能 | 描述 | 状态 |
|------|------|------|
| **品种标准** | 内置常见猫咪品种的体重标准数据 | ✅ |
| **健康分析** | 自动判断体重健康状态 | ✅ |
| **趋势建议** | 提供专业的喂养建议 | ✅ |
| **历史追踪** | 记录体重变化趋势 | ✅ |

### 健康状态分类

| 状态 | 判定条件 | 建议 |
|------|---------|------|
| **偏瘦 (thin)** | 体重 < 标准下限 | 增加营养摄入 |
| **健康 (normal)** | 标准范围内 | 保持当前喂养方式 |
| **偏胖 (overweight)** | 体重 > 标准上限 | 控制饮食，增加运动 |

### 体重分析服务

**文件路径：** `backend/src/services/weightStandard.service.ts`

```typescript
/**
 * 分析猫咪体重健康状态
 */
export async function analyzeCatWeight(
  catId: string,
  userId: string
): Promise<WeightAnalysis | null> {
  // 1. 获取猫咪信息
  const cat = await prisma.cat.findFirst({
    where: { id: catId, userId, isActive: true }
  })

  if (!cat || !cat.weight || !cat.birthDate) {
    return null
  }

  // 2. 计算年龄
  const ageMonths = calculateAgeInMonths(cat.birthDate)

  // 3. 获取品种标准
  const standard = getBreedStandard(
    cat.breed || '中华田园猫',
    cat.gender,
    ageMonths
  )

  if (!standard) {
    return null
  }

  // 4. 分析体重状态
  const current = cat.weight
  const { min, max } = standard

  let status: 'thin' | 'normal' | 'overweight'
  let message: string

  if (current < min) {
    status = 'thin'
    const deficit = min - current
    message = `体重偏轻，比标准下限低 ${deficit.toFixed(1)}kg，建议增加营养摄入`
  } else if (current > max) {
    status = 'overweight'
    const excess = current - max
    message = `体重偏重，比标准上限高 ${excess.toFixed(1)}kg，建议控制饮食并增加运动`
  } else {
    status = 'normal'
    message = '体重在标准范围内，继续保持当前喂养方式'
  }

  // 5. 计算详细指标
  const percentage = ((current - min) / (max - min)) * 100
  const deviation = current - ((min + max) / 2)

  return {
    status,
    message,
    current,
    min,
    max,
    percentage: Math.round(percentage),
    deviation: Number(deviation.toFixed(1))
  }
}
```

### 前端组件

#### WeightStandardCard.vue（体重标准卡片）

**文件路径：** `frontend/src/components/cat/WeightStandardCard.vue`

```vue
<template>
  <div class="weight-standard-card">
    <div v-if="loading" class="loading">
      <LoadingSpinner />
    </div>

    <div v-else-if="analysis" class="card-content">
      <div class="health-status">
        <div class="status-indicator" :class="analysis.status">
          <span class="icon">{{ getStatusIcon(analysis.status) }}</span>
          <span class="text">{{ getStatusText(analysis.status) }}</span>
        </div>
      </div>

      <div class="weight-details">
        <div class="current-weight">
          <span class="label">当前体重</span>
          <span class="value">{{ analysis.current.toFixed(1) }}kg</span>
        </div>

        <div class="standard-range">
          <span class="label">标准范围</span>
          <span class="value">{{ analysis.min }}-{{ analysis.max }}kg</span>
        </div>

        <div class="deviation">
          <span class="label">与标准中值偏差</span>
          <span
            class="value"
            :class="{
              positive: analysis.deviation > 0,
              negative: analysis.deviation < 0
            }"
          >
            {{ analysis.deviation > 0 ? '+' : '' }}{{ analysis.deviation }}kg
          </span>
        </div>
      </div>

      <div class="progress-bar">
        <div
          class="progress-fill"
          :class="analysis.status"
          :style="{ width: `${analysis.percentage}%` }"
        ></div>
      </div>

      <div class="recommendation">
        <p class="recommendation-text">
          {{ analysis.message }}
        </p>
      </div>
    </div>

    <div v-else class="no-data">
      <p>暂无足够数据进行分析</p>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { getWeightAnalysis } from '@/api/weightStandard'

const props = defineProps<{
  catId: string
}>()

const loading = ref(true)
const analysis = ref<WeightAnalysis | null>(null)

onMounted(async () => {
  try {
    const response = await getWeightAnalysis(props.catId)
    analysis.value = response.data
  } catch (error) {
    console.error('获取体重分析失败', error)
  } finally {
    loading.value = false
  }
})

function getStatusIcon(status: string) {
  const icons = {
    thin: '⚠️',
    normal: '✅',
    overweight: '⚠️'
  }
  return icons[status] || '❓'
}

function getStatusText(status: string) {
  const texts = {
    thin: '偏瘦',
    normal: '健康',
    overweight: '偏胖'
  }
  return texts[status] || '未知'
}
</script>
```

## 🔧 API 接口

### 获取体重分析

```http
GET /api/weight-standards/:catId/analysis
Authorization: Bearer <token>
```

**响应示例：**

```json
{
  "success": true,
  "data": {
    "status": "normal",
    "message": "体重在标准范围内，继续保持当前喂养方式",
    "current": 4.2,
    "min": 3.5,
    "max": 5.5,
    "percentage": 47,
    "deviation": -0.3
  }
}
```

## 💡 使用建议

### 用户建议

1. **定期记录体重**
   - 建议每月记录一次体重
   - 使用相同的时间（如月初）
   - 使用相同的秤

2. **关注趋势变化**
   - 查看体重趋势图
   - 注意季节性变化
   - 参考健康状态建议

3. **遵循专业建议**
   - 根据系统建议调整喂养
   - 定期咨询兽医
   - 个性化调整方案
