# 多猫对比功能

> **功能版本:** V3.2
> **更新时间:** 2026-06-04
> **功能状态:** ✅ 已上线

本文档详细描述多猫对比功能的实现细节和使用说明。

---

## 📋 功能概述

多猫对比功能允许用户同时查看 2-5 只猫咪的数据对比，包括：
- 体重趋势对比
- 健康状态对比
- 基本信息对比

---

## 🎯 功能特性

### 核心功能

| 功能 | 描述 | 状态 |
|------|------|------|
| **多选猫咪** | 支持 2-5 只猫咪同时选择 | ✅ |
| **体重对比** | 多系列折线图显示体重趋势 | ✅ |
| **健康对比** | 卡片形式展示健康状态 | ✅ |
| **信息对比** | 表格形式对比基本信息 | ✅ |
| **批量 API** | 后端批量数据接口 | ✅ |

### 限制条件

- 最少选择 2 只猫咪
- 最多选择 5 只猫咪
- 仅支持同用户下的猫咪

```typescript
interface Props {
  modelValue: string[]  // 选中的猫咪ID数组
  max?: number          // 最大选择数量（默认5）
}

// 核心方法
function toggleCat(catId: string) {
  const index = selected.value.indexOf(catId)
  if (index > -1) {
    selected.value = selected.value.filter(id => id !== catId)
  } else {
    if (selected.value.length < props.max) {
      selected.value = [...selected.value, catId]
    }
  }
  emit('update:modelValue', selected.value)
}
```

### 后端实现

#### 控制器（Controller）

**文件路径：** `backend/src/controllers/weightStandard.controller.ts`

```typescript
/**
 * 批量获取多只猫咪的体重分析
 */
export async function getBatchAnalysis(req: Request, res: Response) {
  try {
    const userId = (req as any).user?.userId
    const { catIds } = req.body

    // 验证输入
    if (!Array.isArray(catIds) || catIds.length < 2 || catIds.length > 5) {
      return res.status(400).json(errorResponse('请选择2-5只猫咪进行对比'))
    }

    // 验证所有权
    const cats = await prisma.cat.findMany({
      where: {
        id: { in: catIds },
        userId,
        isActive: true
      }
    })

    if (cats.length !== catIds.length) {
      return res.status(403).json(errorResponse('部分猫咪不存在或无权访问'))
    }

    // 批量分析
    const results: Record<string, any> = {}
    for (const catId of catIds) {
      const analysis = await analyzeCatWeight(catId, userId)
      if (analysis) {
        results[catId] = analysis
      }
    }

    res.json(successResponse(results, '批量分析成功'))
  } catch (error: any) {
    next(error)
  }
}
```

```typescript
/**
 * 批量获取多只猫咪的体重分析
 */
export async function getBatchWeightAnalysis(catIds: string[]) {
  if (catIds.length < 2 || catIds.length > 5) {
    throw new Error('请选择2-5只猫咪进行对比')
  }

  const response = await api.post('/weight-standards/batch', { catIds })
  return response.data
}

/**
 * 批量获取多只猫咪的体重历史
 */
export async function getBatchWeightHistory(catIds: string[]) {
  if (catIds.length < 2 || catIds.length > 5) {
    throw new Error('请选择2-5只猫咪进行对比')
  }

  const response = await api.post('/weight-standards/batch-history', { catIds })
  return response.data
}
```

## 🔧 使用说明

### 用户操作流程

1. **进入对比页面**
   - 点击"我的猫咪"
   - 点击"多猫对比"按钮

2. **选择猫咪**
   - 勾选 2-5 只猫咪
   - 点击"全选"快速选择
   - 点击"清除选择"重置

3. **查看对比**
   - 查看体重趋势图表
   - 查看健康状态卡片
   - 查看基本信息表格

4. **交互操作**
   - 点击图例隐藏/显示猫咪
   - 悬停图表查看详细数据
   - 滚动查看所有对比内容
