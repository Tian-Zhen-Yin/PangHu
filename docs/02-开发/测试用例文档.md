## 1. 测试策略

### 1.1 测试分层

| 层级 | 类型 | 工具 | 覆盖范围 |
|------|------|------|---------|
| 单元测试 | 函数/组件级别 | Vitest | 工具函数、状态管理、业务逻辑 |
| 集成测试 | API级别 | Supertest | 接口联调、数据库交互 |
| E2E测试 | 页面级别 | Playwright | 用户流程、UI交互 |

### 1.2 测试环境

| 环境 | 配置 |
|------|------|
| 数据库 | PostgreSQL (测试库) |
| 后端服务 | http://localhost:3000 |
| 前端服务 | http://localhost:5173 |

### 1.3 前置条件检查

```typescript
// tests/preflight.ts
export async function preflightCheck() {
  const checks = [
    { name: '后端服务', url: 'http://localhost:3000/api/health' },
    { name: '前端服务', url: 'http://localhost:5173' },
  ]
  
  for (const check of checks) {
    try {
      const response = await fetch(check.url)
      if (!response.ok) throw new Error('服务不可达')
      console.log(`✅ ${check.name} 正常`)
    } catch {
      console.error(`❌ ${check.name} 不可达`)
      process.exit(1)
    }
  }
}
```

### 8.2 断言规范

```typescript
// 正确
expect(result).toBe(true)
expect(array).toHaveLength(3)
expect(object).toMatchObject({ key: 'value' })

// 避免
expect(result == true).toBe(true)
expect(array.length).toBe(3)
```
