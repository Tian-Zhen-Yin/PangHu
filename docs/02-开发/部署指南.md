## 🚀 Vercel + Railway 部署（推荐）

### 前端部署到 Vercel

#### 1. 准备工作

```bash
# 确保代码已提交到 Git
git add .
git commit -m "chore: prepare for deployment"
git push origin master
```

#### 2. 连接 Vercel

1. 访问 [Vercel](https://vercel.com/)
2. 使用 GitHub 账号登录
3. 导入项目仓库

#### 3. 配置项目

**构建设置：**

- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `frontend/dist`
- **Install Command**: `npm install --prefix frontend`

**环境变量：**

```
VITE_API_BASE_URL=https://your-backend-url.railway.app
```

#### 4. 部署

点击"Deploy"按钮，Vercel 将自动部署。

部署完成后，你将获得一个 `https://your-project.vercel.app` 地址。

### 后端部署到 Railway

#### 1. 准备工作

创建 `backend/.env.production`：

```bash
# 生产环境配置
PORT=3000
DATABASE_URL=postgresql://user:password@host:port/database
JWT_SECRET=your_production_jwt_secret
JWT_EXPIRES_IN=7d
ZHIPUAI_API_KEY=your_zhipuai_api_key
ZHIPUAI_MODEL=glm-4-flash
NODE_ENV=production
```

#### 2. 连接 Railway

1. 访问 [Railway](https://railway.app/)
2. 使用 GitHub 账号登录
3. 点击"New Project" → "Deploy from GitHub repo"

#### 3. 配置服务

**Root Directory**: `backend`

**Start Command**: `npm start`

**环境变量**：添加 `.env.production` 中的所有变量

#### 4. 添加 PostgreSQL 数据库

1. 在 Railway 项目中点击"New"
2. 选择"PostgreSQL"
3. Railway 会自动提供 `DATABASE_URL`

#### 5. 初始化数据库

```bash
# 在 Railway Console 中运行
npm run db:generate
npm run db:push
```

#### 6. 部署完成

Railway 会提供一个 `https://your-backend.railway.app` 地址。

## 🐳 Docker 部署

### Docker Compose 配置

创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  # 前端服务
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    ports:
      - "80:80"
    depends_on:
      - backend
    environment:
      - VITE_API_BASE_URL=http://backend:3000/api

  # 后端服务
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    ports:
      - "3000:3000"
    depends_on:
      - postgres
    environment:
      - PORT=3000
      - DATABASE_URL=postgresql://postgres:password@postgres:5432/hajimi
      - JWT_SECRET=${JWT_SECRET}
      - ZHIPUAI_API_KEY=${ZHIPUAI_API_KEY}
    volumes:
      - ./backend:/app
      - /app/node_modules

  # PostgreSQL 数据库
  postgres:
    image: postgres:15
    environment:
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=hajimi
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

### 部署命令

```bash
# 构建并启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

## 🌐 自定义服务器部署

### 系统要求

- **操作系统**: Ubuntu 20.04+ / CentOS 8+
- **Node.js**: 18.x+
- **Nginx**: 1.18+
- **PostgreSQL**: 14+

### 部署步骤

#### 1. 安装依赖

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 Nginx
sudo apt install -y nginx

# 安装 PostgreSQL
sudo apt install -y postgresql postgresql-contrib
```

#### 2. 配置 PostgreSQL

```bash
# 创建数据库
sudo -u postgres psql

CREATE DATABASE hajimi;
CREATE USER hajimi_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE hajimi TO hajimi_user;
\q
```

#### 3. 部署后端

```bash
# 克隆代码
git clone https://github.com/Tian-Zhen-Yin/PangHu.git
cd PangHu/backend

# 安装依赖
npm install

# 配置环境变量
cat > .env << EOF
PORT=3000
DATABASE_URL=postgresql://hajimi_user:your_password@localhost:5432/hajimi
JWT_SECRET=$(openssl rand -base64 32)
ZHIPUAI_API_KEY=your_api_key
EOF

# 初始化数据库
npm run db:generate
npm run db:push

# 使用 PM2 启动
npm install -g pm2
pm2 start npm --name "hajimi-backend" -- start
pm2 save
pm2 startup
```

#### 4. 部署前端

```bash
# 构建前端
cd ../frontend
npm install
npm run build

# 配置 Nginx
sudo cat > /etc/nginx/sites-available/hajimi << EOF
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/hajimi;
    index index.html;

    location / {
        try_files \$uri \$uri/ /index.html;
    }

    location /api {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade \$http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host \$host;
        proxy_cache_bypass \$http_upgrade;
    }
}
EOF

# 启用配置
sudo ln -s /etc/nginx/sites-available/hajimi /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

# 复制构建文件
sudo mkdir -p /var/www/hajimi
sudo cp -r dist/* /var/www/hajimi/
```

#### 5. 配置 SSL（可选）

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取 SSL 证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

## 🔄 CI/CD 配置

### GitHub Actions

创建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy

on:
  push:
    branches: [master]

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Deploy to Vercel
        run: vercel --prod --token=\${{ secrets.VERCEL_TOKEN }}

      - name: Deploy to Railway
        run: railway up --service=backend --token=\${{ secrets.RAILWAY_TOKEN }}
```

## 📊 监控与维护

### 日志管理

```bash
# PM2 日志
pm2 logs hajimi-backend

# Nginx 日志
sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log
```

```bash
# 备份
pg_dump -U hajimi_user hajimi > backup.sql

# 恢复
psql -U hajimi_user hajimi < backup.sql
```

## 🆘 故障排查

部署后遇到问题？查看 [故障排查指南](./故障排查.md)

### 常见问题

| 问题 | 解决方案 |
|------|---------|
| **端口被占用** | 更改 PORT 配置 |
| **数据库连接失败** | 检查 DATABASE_URL |

| **CORS 错误** | 配置后端 CORS |
