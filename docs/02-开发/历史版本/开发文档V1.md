# 哈吉咪养成计划 - 开发文档

## 项目简介

哈吉咪养成计划是一个专注于猫咪养护的全栈Web应用，提供从幼猫到成年的全程陪伴式养护指导。项目采用前后端分离架构，使用现代化的技术栈构建。

## 技术栈

### 前端
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **语言**: TypeScript
- **状态管理**: Pinia
- **路由**: Vue Router
- **UI组件库**: Element Plus
- **样式**: Tailwind CSS + Scoped CSS
- **HTTP客户端**: Axios
- **Markdown渲染**: Marked + Highlight.js

### 后端
- **运行时**: Node.js
- **框架**: Express
- **语言**: TypeScript
- **数据库**: SQLite (开发环境)
- **ORM**: Prisma
- **认证**: JWT (jsonwebtoken)
- **密码加密**: bcryptjs
- **数据验证**: express-validator
- **AI服务**: 智谱AI GLM-4-flash

## 数据库设计

### Prisma Schema

```prisma
// 用户
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  username  String   @unique
  password  String
  conversations Conversation[]
  userPlans UserPlan[]
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}

// 养成指南
model Guide {
  id          String   @id @default(cuid())
  title       String
  category    String
  content     String
  ageStage    String?
  sortOrder   Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}

// 计划模板
model Template {
  id          String       @id @default(cuid())
  name        String
  description String
  category    String
  ageStage    String
  tasks       Task[]
  userPlans   UserPlan[]
  createdAt   DateTime     @default(now())
  updatedAt   DateTime     @updatedAt
}

// 模板任务
model Task {
  id          String   @id @default(cuid())
  templateId  String
  title       String
  description String
  deadline    Int
  taskType    String
  completed   Boolean  @default(false)
  template    Template @relation(fields: [templateId], references: [id], onDelete: Cascade)
  createdAt   DateTime @default(now())
}

// 用户计划
model UserPlan {
  id          String    @id @default(cuid())
  userId      String
  templateId  String
  name        String
  isActive    Boolean   @default(false)
  completed   Boolean   @default(false)
  tasks       TaskProgress[]
  user        User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  template    Template  @relation(fields: [templateId], references: [id], onDelete: Cascade)
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
}

// 任务进度
model TaskProgress {
  id          String   @id @default(cuid())
  planId      String
  taskId      String
  completed   Boolean  @default(false)
  completedAt DateTime?
  plan        UserPlan @relation(fields: [planId], references: [id], onDelete: Cascade)
  createdAt   DateTime @default(now())
}

// AI对话
model Conversation {
  id        String   @id @default(cuid())
  userId    String
  title     String   @default("新对话")
  messages  Message[]
  user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}

// 聊天消息
model Message {
  id             String        @id @default(cuid())
  conversationId String
  conversation   Conversation  @relation(fields: [conversationId], references: [id], onDelete: Cascade)
  role           String        // 'user' | 'assistant' | 'system'
  content        String
  markdownContent String?
  referencedGuides String?
  metadata        String?
  createdAt       DateTime      @default(now())
}
```

## API文档

### 认证接口

#### 用户注册
```
POST /api/auth/register
Content-Type: application/json

Request:
{
  "email": "user@example.com",
  "username": "用户名（支持中文）",
  "password": "password123"
}

Response:
{
  "success": true,
  "message": "注册成功",
  "data": {
    "user": {...},
    "token": "jwt_token_here"
  }
}
```

#### 用户登录
```
POST /api/auth/login
Content-Type: application/json

Request:
{
  "account": "user@example.com or username",
  "password": "password123"
}

Response:
{
  "success": true,
  "message": "登录成功",
  "data": {
    "user": {...},
    "token": "jwt_token_here"
  }
}
```

#### 获取当前用户
```
GET /api/auth/me
Authorization: Bearer {token}

Response:
{
  "success": true,
  "data": {
    "id": "...",
    "email": "...",
    "username": "...",
    "createdAt": "...",
    "updatedAt": "..."

}
```

  "content": "用户消息"

Response (Server-Sent Events):
event: connected
data: SSE connected

event: message_start
data: {"content":"消"}

event: message_chunk
data: {"content":"息"}

event: message_done
data: {"model":"glm-4-flash","latency":1234}

## 开发指南

### 添加新页面

1. 在 `frontend/src/views/` 创建新文件夹和组件
2. 在 `frontend/src/router/index.ts` 添加路由
3. 如需认证，设置 `meta.requiresAuth: true`

### 添加新API

1. 在后端 `src/controllers/` 创建控制器
2. 在 `src/routes/` 添加路由定义
3. 在 `src/routes/index.ts` 注册路由
4. 在前端 `src/api/` 创建API函数

### 状态管理

使用Pinia进行状态管理， stores位于 `frontend/src/stores/`：
- `auth.ts` - 认证状态
- `chat.ts` - 聊天状态
- `guide.ts` - 指南状态
- `template.ts` - 模板状态

### AI服务集成

AI服务位于 `backend/src/services/ai.service.ts`：
- `sendMessage()` - 非流式调用
- `sendMessageStream()` - SSE流式调用
- `buildMessages()` - 构建对话上下文
- `generateToken()` - 生成智谱AI JWT Token

## 常见问题

### Q: Prisma迁移失败
A: 删除 `node_modules/.prisma` 目录后重新运行 `npm run db:generate`

### Q: AI服务超时
A: 检查智谱AI API密钥是否正确，网络是否可访问

### Q: 前端跨域问题
A: 开发环境Vite已配置代理，生产环境需配置CORS

### Q: JWT验证失败
A: 检查 `JWT_SECRET` 是否一致，token是否过期
