# 哈吉咪养成计划 - 开发文档 V2.0

## 项目简介

哈吉咪养成计划是一个专注于猫咪养护的全栈Web应用，提供从幼猫到成年的全程陪伴式养护指导。项目采用前后端分离架构，使用现代化的技术栈构建。

**V2.0 更新**：新增多猫咪管理系统、疫苗接种记录管理、AI上下文增强等功能。

---

## 技术栈

### 前端
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **语言**: TypeScript
- **状态管理**: Pinia + pinia-plugin-persistedstate
- **路由**: Vue Router
- **UI组件库**: Element Plus
- **样式**: Tailwind CSS + Scoped CSS
- **HTTP客户端**: Axios
- **Markdown渲染**: Marked + Highlight.js

### 后端
- **运行时**: Node.js
- **框架**: Express
- **语言**: TypeScript
- **数据库**: SQLite (开发环境)
- **ORM**: Prisma
- **认证**: JWT (jsonwebtoken)
- **密码加密**: bcryptjs
- **数据验证**: express-validator
- **AI服务**: 智谱AI GLM-4-flash
- **流式响应**: Server-Sent Events (SSE)

- Node.js >= 18.0.0


## V2.0 数据库设计

### Prisma Schema 更新

#### 新增模型：Cat（猫咪档案）

```prisma
model Cat {
  id          String   @id @default(cuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id], onDelete: Cascade)

  // 基本信息
  name        String
  avatar      String?
  breed       String?
  gender      String   @default("unknown")
  birthDate   DateTime
  adoptDate   DateTime?

  // 健康信息
  weight      Float?
  isNeutered  Boolean  @default(false)
  neuteredDate DateTime?

  // 特殊标记
  color       String?
  features    String?
  allergies   String?
  diseases    String?

  // 状态
  isActive    Boolean  @default(true)

  // 关联
  records     PetRecord[]
  vaccines    VaccineRecord[]
  conversations Conversation[]

  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@index([userId])
  @@index([userId, isActive])
}
```

#### 新增模型：VaccineRecord（疫苗记录）

```prisma
model VaccineRecord {
  id           String   @id @default(cuid())
  catId        String
  cat          Cat      @relation(fields: [catId], references: [id], onDelete: Cascade)

  // 疫苗信息
  vaccineName  String
  vaccineType  String
  manufacturer String?
  batchNumber  String?

  // 接种信息
  vaccinatedAt DateTime
  nextDueDate  DateTime?
  veterinarian String?
  clinic       String?

  // 反应记录
  reaction     String?
  notes        String?

  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt

  @@index([catId])
  @@index([catId, vaccinatedAt])
}
```

#### 修改模型：PetRecord（成长记录）

```prisma
model PetRecord {
  id          String   @id @default(cuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id], onDelete: Cascade)

  catId       String   // 新增：关联到具体的猫咪
  cat         Cat      @relation(fields: [catId], references: [id], onDelete: Cascade)

  // 移除 petName 字段，改为通过 cat 关联获取

  recordDate  DateTime
  weight      Float?
  height      Float?
  mood        String?
  activity    String?
  food        String?
  notes       String?
  photos      String?

  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@index([userId])
  @@index([catId])
  @@index([catId, recordDate])
}
```

#### 修改模型：Conversation（对话）

```prisma
model Conversation {
  id        String    @id @default(cuid())
  userId    String
  user      User      @relation(fields: [userId], references: [id], onDelete: Cascade)

  catId     String?   // 新增：关联的猫咪ID（可选）
  cat       Cat?      @relation(fields: [catId], references: [id], onDelete: SetNull)

  title     String
  messages  Message[]

  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt

  @@index([userId])
  @@index([catId])
}
```

## 前端开发指南

### 状态管理

#### Cat Store（猫咪状态）

**文件**：`frontend/src/stores/myCat.ts`

```typescript
import { defineStore } from 'pinia'
import { ref } from 'vue'

export const useMyCatStore = defineStore('myCat', () => {
  const cats = ref<Cat[]>([])
  const currentCat = ref<Cat | null>(null)

  // 获取猫咪列表
  async function fetchCats() {
    const response = await getCats()
    cats.value = response.data

    // 恢复上次选择的猫咪
    const savedCatId = localStorage.getItem('currentCatId')
    if (savedCatId) {
      currentCat.value = cats.value.find(c => c.id === savedCatId) || null
    }
  }

  // 选择猫咪
  function selectCat(cat: Cat) {
    currentCat.value = cat
    localStorage.setItem('currentCatId', cat.id)
  }

  return { cats, currentCat, fetchCats, selectCat }
})
```

**持久化配置**：
```typescript
// pinia 持久化配置
import { createPinia } from 'pinia'
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'

const pinia = createPinia()
pinia.use(piniaPluginPersistedstate)
```

**文件**：`frontend/src/components/cat/CatSelector.vue`

```vue
<template>
  <div class="cat-selector" v-click-outside="closeDropdown">
    <!-- 当前猫咪显示 -->
    <div class="current-cat" @click="toggleDropdown">
      <div class="cat-avatar">
        <img v-if="currentCat?.avatar" :src="currentCat.avatar" />

      </div>
      <span v-else class="no-cat">选择猫咪</span>
      <span class="arrow">▼</span>
    </div>

    <!-- 下拉列表 -->
    <div v-if="showDropdown" class="cat-dropdown">
      <div
        v-for="cat in cats"
        :key="cat.id"
        @click="selectCat(cat)"
        :class="['cat-item', { active: cat.id === currentCat?.id }]"
      >
        <img :src="cat.avatar || '/default-cat.png'" />
        <div class="cat-info">
          <div class="name">{{ cat.name }}</div>
          <div class="age">{{ cat.ageFormatted }}</div>
        </div>
      </div>

      <RouterLink to="/my-cats/new" class="add-cat">
        <span>➕ 添加新猫咪</span>
      </RouterLink>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import { useMyCatStore } from '@/stores/myCat'
import { storeToRefs } from 'pinia'

const myCatStore = useMyCatStore()
const { cats, currentCat } = storeToRefs(myCatStore)
const showDropdown = ref(false)

function toggleDropdown() {
  showDropdown.value = !showDropdown.value
}

function closeDropdown() {
  showDropdown.value = false
}

function selectCat(cat: Cat) {
  myCatStore.selectCat(cat)
  closeDropdown()
}
</script>
```

```typescript
export async function getCatContext(catId: string, userId: string) {
  const cat = await prisma.cat.findFirst({
    where: { id: catId, userId, isActive: true },
    include: {
      vaccines: {
        orderBy: { vaccinatedAt: 'desc' },
        take: 3
      },
      records: {
        orderBy: { recordDate: 'desc' },
        take: 1
      }
    }
  })

  if (!cat) return null

  return {
    id: cat.id,
    name: cat.name,
    breed: cat.breed,
    gender: cat.gender,
    ageMonths: calculateAgeInMonths(cat.birthDate),
    ageFormatted: formatAge(calculateAgeInMonths(cat.birthDate)),
    weight: cat.weight,
    isNeutered: cat.isNeutered,
    allergies: cat.allergies,
    diseases: cat.diseases,
    recentVaccines: cat.vaccines.map(v => ({
      name: v.vaccineName,
      date: v.vaccinatedAt.toISOString(),
      nextDueDate: v.nextDueDate?.toISOString()
    })),
    lastRecord: cat.records[0] ? {
      date: cat.records[0].recordDate.toISOString(),
      weight: cat.records[0].weight,
      notes: cat.records[0].notes
    } : null
  }
}

// 年龄计算工具函数
export function calculateAgeInMonths(birthDate: Date): number {
  const now = new Date()
  const years = now.getFullYear() - birthDate.getFullYear()
  const months = now.getMonth() - birthDate.getMonth()
  return Math.max(0, years * 12 + months)
}

export function formatAge(months: number): string {
  const years = Math.floor(months / 12)
  const remainingMonths = months % 12
  if (years === 0) return `${remainingMonths}个月`
  if (remainingMonths === 0) return `${years}岁`
  return `${years}岁${remainingMonths}个月`
}
```

```typescript
export interface CatContext {
  id: string
  name: string
  breed?: string | null
  gender: string
  ageMonths: number
  ageFormatted: string
  weight?: number | null
  isNeutered: boolean
  allergies?: string | null
  diseases?: string | null

    name: string
    date: string
    nextDueDate?: string | null
  }>

    date: string
    weight?: number | null
    notes?: string | null
  } | null

export async function buildMessages(
  history: ServiceChatMessage[],
  catContext?: CatContext,
  useRAG: boolean = true,
  apiKey: string = ''
): Promise<{ messages: any[]; citations?: Citation[] }> {
  // 构建猫咪上下文提示词
  const catContextPrompt = catContext ? buildCatContextPrompt(catContext) : ''

  // 系统消息
  const systemMessage = {
    role: 'system',
    content: `${catContextPrompt}

你是一位专业的猫咪养护顾问，拥有丰富的猫咪健康知识和养护经验。
请根据猫咪的具体情况提供个性化的建议。`
  }

  const messages = [systemMessage, ...history.map(m => ({
    role: m.role,
    content: m.content
  }))]

  // RAG 检索（可选）
  let citations: Citation[] | undefined
  if (useRAG && catContext && history.length > 0) {
    const userQuery = history[history.length - 1].content
    const ageStage = catContext.ageMonths < 12 ? '幼猫期' :
                     catContext.ageMonths < 84 ? '成年期' : '老年期'

    const ragResult = await retrieveKnowledge(userQuery, apiKey, {
      topK: 3,
      minScore: 0.5,
      ageStage  // 根据猫咪年龄阶段优先检索
    })

    if (ragResult.chunks.length > 0) {
      const ragPrompt = buildRAGPrompt(ragResult.chunks)
      messages.push({
        role: 'system',
        content: ragPrompt
      })
      citations = ragResult.citations
    }
  }

  return { messages, citations }
}

function buildCatContextPrompt(catContext: CatContext): string {
  const genderText = catContext.gender === 'male' ? '公猫' :
                     catContext.gender === 'female' ? '母猫' : '未知'

  return `
## 当前咨询的猫咪档案
- 名字：${catContext.name}
- 品种：${catContext.breed || '未知'}
- 性别：${genderText}
- 年龄：${catContext.ageFormatted}
- 体重：${catContext.weight ? `${catContext.weight}kg` : '未记录'}
- 绝育状态：${catContext.isNeutered ? '已绝育' : '未绝育'}
${catContext.allergies ? `- 过敏信息：${catContext.allergies}` : ''}
${catContext.diseases ? `- 既往病史：${catContext.diseases}` : ''}
${catContext.recentVaccines.length > 0 ? `- 近期疫苗：${catContext.recentVaccines.map(v => v.name).join('、')}` : ''}

**请根据以上猫咪的具体情况提供个性化建议。**
`
}
```

## 开发常见问题

### Q: Prisma 迁移失败？

A: 删除 `node_modules/.prisma` 目录后重新运行：
```bash
rm -rf node_modules/.prisma
npm run db:generate
npm run db:push
```

### Q: TypeScript 编译错误？

A: 使用 `--transpile-only` 模式避免缓存问题：
```bash
# package.json
"dev": "nodemon --exec \"ts-node --transpile-only\" src/server.ts"
```

### Q: AI 上下文没有生效？

A: 检查以下几点：
1. `catId` 是否正确传递到后端
2. `getCatContext()` 是否正确获取猫咪数据
3. `buildMessages()` 是否使用了 `catContext` 参数
4. 查看后端日志确认系统提示词内容

### Q: 猫咪选择器状态不持久？

A: 确保 Pinia 配置了持久化插件：
```typescript
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'

const pinia = createPinia()
pinia.use(piniaPluginPersistedstate)
```

### Q: 疫苗时间线不显示？

A: 检查：
1. `vaccines` 数组是否有数据
2. `formatDate()` 函数是否正确处理日期格式
3. CSS 样式是否正确应用
