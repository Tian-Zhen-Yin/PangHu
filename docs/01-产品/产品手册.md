# 哈吉咪养成计划 - 产品手册 V3.0

## 产品概述

**哈吉咪养成计划**是一款智能猫咪健康管理应用，结合了AI技术、RAG知识库检索、个性化档案管理和可视化数据分析，为猫咪主人提供全方位的养护指导。

### 核心价值

- **多猫咪管理**：一个账户管理多只猫咪档案，每只猫独立的健康记录
- **AI智能咨询**：根据猫咪的具体情况（年龄、体重、疫苗、健康状况）提供个性化建议
- **养护知识库**：187个知识块，涵盖疫苗、喂养、训练、健康等20个指南
- **成长时间线**：记录每只猫咪的成长轨迹和健康变化
- **体重趋势可视化**：直观展示体重变化曲线，健康状态一目了然

## V3.1/V3.2 新功能

### 多猫对比功能 📊

全新多猫对比功能，支持同时对比 2-5 只猫咪的健康数据：

#### 核心特性

- **多猫选择器**：复选框模式，最多选择 5 只猫咪
- **三种对比维度**：
  - 体重趋势对比（多系列折线图）
  - 健康状态对比（卡片展示）
  - 基本信息对比（表格形式）
- **不同颜色区分**：每只猫咪使用独立颜色
- **实时数据**：自动获取最新体重分析
- **交互式图表**：ECharts 多系列图表支持图例切换

#### 功能入口

```
我的猫咪 → 📊 多猫对比
```

#### 使用流程

1. 点击"多猫对比"按钮进入对比页面
2. 使用复选框选择 2-5 只猫咪
3. 点击"开始对比"按钮
4. 在三个选项卡中查看不同维度的对比数据

#### 对比维度说明

**体重趋势对比**
- 多条折线在同一图表中
- 每只猫咪使用不同颜色
- 显示标准范围阴影
- 图例支持点击隐藏/显示

**健康状态对比**
- 卡片网格布局
- 显示当前体重、健康状态
- 标准范围和偏差值
- 可视化健康徽章

**基本信息对比**
- 表格形式对比
- 品种、性别、年龄等信息
- 头像辅助识别

## 用户指南

### 多猫对比

#### 访问入口

1. 进入「我的猫咪」页面
2. 点击顶部「📊 多猫对比」按钮（需至少有 2 只猫咪）

#### 选择猫咪

- 在猫咪列表中使用复选框选择 2-5 只猫咪
- 顶部显示已选数量提示（已选 X / 5 只）
- 支持全选和清除选择操作

#### 开始对比

1. 选择好猫咪后，点击「开始对比」按钮
2. 系统自动获取各猫咪的体重分析和历史数据
3. 默认显示体重趋势对比图

#### 对比维度切换

**体重趋势对比**
- 多条折线展示各猫体重变化
- 不同颜色区分猫咪
- 鼠标悬停显示详细数据
- 点击图例可隐藏/显示特定猫咪

**健康状态对比**
- 卡片形式展示每只猫的健康分析
- 当前体重和健康状态徽章
- 标准范围和偏差值

**基本信息对比**
- 表格形式对比基础信息
- 品种、性别、年龄等
- 便于快速比较差异

#### 限制说明

- 最少选择 2 只猫咪
- 最多选择 5 只猫咪
- 需要猫咪有体重记录才能显示趋势图

### 查看体重趋势

1. 进入「我的猫咪」页面
2. 点击任意猫咪卡片进入详情页
3. 向下滚动查看「体重趋势」图表
4. 鼠标悬停在数据点上查看详细信息

#### 图表说明

| 元素 | 说明 |
|------|------|
| 橙色曲线 | 体重变化趋势 |
| 渐变填充 | 视觉美化效果 |
| 虚线 | 平均体重参考线 |
| 数据点 | 实际测量记录 |
| 悬停提示 | 显示日期、体重、备注 |

### 添加体重记录

体重记录通过「养成时间线」添加：

1. 进入「养成时间线」页面
2. 选择对应猫咪
3. 点击「添加记录」
4. 填写体重信息
5. 保存后自动更新趋势图

### 导出数据（规划中）

未来版本将支持：
- 导出体重趋势为 CSV
- 生成健康报告 PDF
- 数据对比分析

## 数据模型

### WeightHistoryRecord（体重历史记录）

```typescript
interface WeightHistoryRecord {
  date: string      // 记录日期 (YYYY-MM-DD)
  weight: number    // 体重 (kg)
  notes?: string    // 备注信息
}
```

### 体重历史 API

#### 获取猫咪体重历史

```http
GET /api/my-cats/:catId/weight-history
Authorization: Bearer <token>
```

**响应示例**：
```json
{
  "success": true,
  "message": "获取体重历史成功",
  "data": [
    {
      "date": "2023-06-15",
      "weight": 1.24,
      "notes": "体重1.2kg，健康成长中"
    },
    {
      "date": "2023-06-29",
      "weight": 1.48,
      "notes": "体重1.5kg，健康成长中"
    }
  ]
}
```

**数据说明**：
- 返回记录按日期升序排列
- 包含猫咪档案中的初始体重（如果有）
- 自动过滤掉无体重的记录

## 常见问题

### Q: 体重趋势图不显示？

A: 请检查以下几点：
1. 确认已为该猫咪添加了体重记录
2. 检查浏览器控制台是否有错误
3. 刷新页面重试
4. 确保已登录账户

### Q: 图表数据可以导出吗？

A: 目前暂不支持导出，该功能已在规划中（V3.1）。

### Q: 体重记录可以修改吗？

A: 可以。在养成时间线页面找到对应记录，点击编辑即可。

### Q: 初始体重是如何计算的？

A: 系统会检查：
1. 猫咪档案中记录的体重（作为创建时的初始体重）
2. 第一条成长记录中的体重
3. 取较早的作为起点

### Q: 图表支持多只猫咪对比吗？

A: 支持！V3.1 版本已新增多猫对比功能：
- 最多可同时对比 5 只猫咪
- 支持体重趋势、健康状态、基本信息三个维度
- 在「我的猫咪」页面点击「📊 多猫对比」即可使用

### Q: 多猫对比功能有什么用？

A: 多猫对比适用于以下场景：
- 多猫家庭观察各猫生长差异
- 对比不同品种/性别的体重增长
- 发现某只猫的健康异常
- 评估喂养方式的效果
