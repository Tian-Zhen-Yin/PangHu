# 哈吉咪养成计划 - 产品手册 V4.0

## 产品概述

**哈吉咪养成计划**是一款智能猫咪健康管理应用。V4.0 引入 AI 智能顾问"喵喵医生"，结合你的猫咪档案、养护知识库智能检索、个性化档案管理和可视化数据分析，为你提供全方位的养护指导。

### 核心价值

- **喵喵医生 AI 顾问**：基于猫咪的具体情况（年龄、体重、疫苗、健康状况）一步步调用工具、给出个性化建议，过程透明可见
- **多猫咪管理**：一个账户管理多只猫咪档案，每只猫独立的健康记录
- **体重健康可视化**：体重趋势图表 + 品种健康标准 + 多猫对比，健康状态一目了然
- **养护知识库**：187 个知识块，涵盖疫苗、喂养、训练、健康等 20 个指南
- **养成时间线**：记录每只猫咪的成长轨迹和健康变化

### V4.0 更新亮点

- 🤖 **喵喵医生 AI 智能顾问上线**：按需调用多项能力，建议更个性化
- 📊 **执行过程可视化**：你能看到喵喵医生如何一步步读取档案、评估健康
- 💾 **多轮对话记忆**：喵喵医生记得你上一句说了什么，对话更连贯
- 🔀 **智能 / 普通双模式**：喜欢简洁或喜欢详细，由你选择

## 喵喵医生 · AI 智能顾问

喵喵医生是哈吉咪养成计划的 AI 智能顾问。和普通聊天机器人不同，它能根据**你猫咪的实际档案**（品种、年龄、体重、疫苗、健康状况）一步步读取数据、给出个性化建议，整个过程对你透明可见。

### 智能模式与普通模式

喵喵医生支持两种对话模式：

| 模式 | 特点 | 适合场景 |
|------|------|----------|
| 🤖 **智能模式**（默认） | 展示工具调用过程与信息卡片，建议更详细、有据可查 | 想了解健康状况、获取个性化建议 |
| 💬 **普通模式** | 简洁的对话气泡，快速问答 | 简单闲聊、快速查询 |

你将可以在对话界面切换模式。

### 对话时你能看到什么

在智能模式下，喵喵医生的每条回复会包含以下几个部分：

```text
┌─────────────────────────────────────────────┐
│ 🤖 喵喵医生                                  │
│                                              │
│ ▼ 执行轨迹（可展开查看）                     │
│   1. 识别意图 → 健康咨询                     │
│   2. 读取猫咪档案 + 评估健康                 │
│   3. 生成个性化建议                          │
│                                              │
│ 🔧 喵喵医生正在查看：                        │
│   🐱 猫咪档案      ✓ 已读取                 │
│   ✅ 健康评估      ✓ 已完成                 │
│   💉 疫苗状态      ✓ 已检查                 │
│                                              │
│ ┌─────────────┐ ┌──────────────────┐        │
│ │ 🐱 奶糖      │ │ ✅ 健康：正常     │        │
│ │ 英短·2岁3个月│ │ 4.52kg 偏差+0.12 │        │
│ └─────────────┘ └──────────────────┘        │
│                                              │
│ 根据奶糖的健康数据，本周体重保持稳定……       │
│                                              │
│ 📚 知识参考：《幼猫养护指南》《疫苗指南》    │
└─────────────────────────────────────────────┘
```

- **执行轨迹**：展示喵喵医生从理解你的问题到给出建议的处理步骤。需要说明的是，这是**喵喵医生执行流程的可视化**，方便你了解它做了什么；它展示的不是 AI 的内部思考过程。
- **工具调用进度**：实时显示喵喵医生正在读取哪些数据（猫咪档案、健康评估、疫苗状态、知识库等），每项完成后打勾。
- **摘要卡片**：关键数据以卡片形式直观呈现，如猫咪基本信息、健康状态、体重偏差。
- **引用来源**：当建议参考了知识库时，底部会列出引用的指南，点击可跳转查看原文。

### 喵喵医生记得你

喵喵医生具有多轮对话记忆能力：它记得你这一轮刚刚说过的话、问过的问题，所以你们可以连续追问，而不必每次都重复背景信息。同时，它会结合你当前选中猫咪的档案来给出个性化建议——换一只猫，建议也会随之不同。

### 常见对话示例

| 你的问题 | 喵喵医生会怎么做 |
|----------|------------------|
| 「奶糖最近体重有变化吗？」 | 读取猫咪档案 → 分析体重趋势 → 评估健康状态，给出趋势判断与建议 |
| 「它的疫苗该打了吗？」 | 检查疫苗记录 → 对比接种时间，提醒下次到期 |
| 「英短公猫正常体重是多少？」 | 检索知识库 → 结合品种标准，给出正常体重范围并附知识参考 |

> 后续每个功能章节末尾，都会标注该功能如何与喵喵医生联动。

## 猫咪健康管理

### 体重趋势图表

哈吉咪养成计划使用体重趋势曲线图，直观展示猫咪体重随时间的变化：

```text
┌─────────────────────────────────────────┐
│  体重趋势           当前体重: 5.2kg     │
│                                         │
│  6kg ┤         ╱╲                       │
│  5kg ┤       ╱──╲╲    ╱──╮             │
│  4kg ┤     ╱─────╲╲╲──╲  ╲             │
│  3kg ┤   ╱─────────╲────╲─╲────         │
│      └────────────────────────────→    │
│      2023-06  2023-09  2023-12         │
│  ───── 平均值: 4.8kg                    │
└─────────────────────────────────────────┘
```

**核心特性**：平滑曲线、平均值参考线、鼠标悬停显示详细数据、当前体重置顶显示。

**智能分析**：自动识别体重增长/下降/稳定趋势，结合年龄评估体重是否健康，异常变化时给出提示。

**查看方式**：进入「我的猫咪」→ 点击猫咪卡片进入详情页 → 向下滚动查看「体重趋势」。

#### 添加体重记录

体重记录通过「养成时间线」添加：进入养成时间线 → 选择猫咪 → 添加记录 → 填写体重 → 保存后自动更新趋势图。

#### 🤖 与喵喵医生联动

直接问喵喵医生「奶糖体重怎么样？」或「它最近胖了吗？」，喵喵医生会自动读取体重趋势、结合品种标准评估健康状况，并用卡片展示当前体重、标准范围和偏差，再给出文字建议——无需你自己翻图表。

---

### 体重健康标准

不同品种、年龄的猫咪，健康体重范围不同。为了让判断更准确，我们内置了各品种的标准体重数据系统：

- **品种标准**：内置各品种的标准体重区间（如英短公猫约 3.5–5.5 kg）
- **健康状态分析**：基于当前体重与标准范围对比，给出「偏瘦/正常/偏胖」判断与偏差值
- **可视化徽章**：健康状态以直观徽章呈现

#### 🤖 与喵喵医生联动

喵喵医生评估健康时，会自动套用你猫咪所属品种的标准范围，并结合年龄、绝育状态等因素综合判断，而不仅是简单对比数字。

| 基本信息对比 | 表格形式，品种、性别、年龄等一目了然 |

## 猫咪档案与成长

### 多猫咪管理

一个账户可以管理多只猫咪，每只猫拥有独立的档案与健康记录。切换猫咪只需在应用顶部的猫咪选择器操作，所有页面（时间线、体重、疫苗、喵喵医生对话）都会跟随切换。

档案信息包括：名字、头像、品种、性别、出生日期、绝育状态、既往病史等。

#### 🤖 与喵喵医生联动

每只猫的档案是喵喵医生给出个性化建议的基础——品种决定标准体重、年龄影响健康评估、绝育状态关系到喂养建议。档案越完整，喵喵医生的建议越精准。

---

### 养成时间线

养成时间线记录每只猫咪的成长轨迹，支持添加体重、状态备注等记录。每次添加体重记录后，体重趋势图会自动更新。

**添加记录**：进入「养成时间线」→ 选择猫咪 → 点击「添加记录」→ 填写信息 → 保存。

**修改记录**：在时间线中找到对应记录，点击编辑即可。

#### 🤖 与喵喵医生联动

喵喵医生的建议会参考时间线里的历史记录。例如你持续记录体重，它能更准确地判断趋势；记录了病症或异常，它会在健康咨询时纳入考量。

---

### 疫苗管理

集中管理每只猫咪的疫苗接种记录与到期提醒。

- **接种记录**：记录疫苗名称、接种日期、下次到期时间
- **到期提醒**：接近到期时主动提示
- **查看入口**：疫苗管理页面，或在猫咪详情页快捷查看

#### 🤖 与喵喵医生联动

直接问喵喵医生「它该打疫苗了吗？」「下次疫苗什么时候？」，它会检查疫苗记录并提醒下次到期时间，省去你自己翻找的麻烦。

## 养护知识库

哈吉咪养成计划内置养护知识库，包含 **187 个知识块**，涵盖疫苗、喂养、训练、健康、行为等 **20 个指南**，供你随时查阅科学养护方法。

当喵喵医生回答你的问题时，会从知识库里检索相关内容作为参考。

### 🤖 与喵喵医生联动

当喵喵医生的回答参考了知识库内容时，会在回复底部列出「📚 知识参考」，点击即可跳转到对应指南详情。这意味着喵喵医生的建议**有据可查、可溯源**，而非凭空生成。

> 专业建议仅供参考，具体诊疗请以兽医为准。若猫咪出现紧急症状，请立即就医。

## 常见问题

### Q: 智能模式和普通模式有什么区别？

A: 智能模式下，喵喵医生会展示它一步步读取档案、评估健康的过程，并给出信息卡片和带知识参考的详细建议，适合了解健康状况。普通模式是简洁的对话气泡，适合快速问答。你可以在对话界面随时切换。

### Q: 喵喵医生为什么会显示"工具调用"？

A: 这是喵喵医生读取你猫咪数据的过程可视化——比如它要先知道是哪只猫、读取档案、查看体重趋势，才能给出个性化建议。展示这个过程是为了让你清楚它的建议是基于你的实际数据，而不是凭空生成。

### Q: 喵喵医生记得我之前说过的话吗？

A: 是的。喵喵医生具有多轮对话记忆，会记得你这一轮对话中刚刚聊过的内容，所以可以连续追问。切换到新对话窗口后，记忆会重置。

### Q: 喵喵医生的建议靠谱吗？

A: 喵喵医生的建议会引用知识库来源（底部「📚 知识参考」可点击跳转原文），做到有据可查。但需要注意，这些建议属于**参考性建议，具体诊疗请以兽医为准**。若猫咪出现紧急症状，请立即就医。

### Q: 体重趋势图不显示？

A: 请检查：① 已为该猫咪添加体重记录；② 已登录账户；③ 刷新页面重试；④ 如仍有问题，可截图反馈给客服。

### Q: 体重记录可以修改吗？

A: 可以。在养成时间线页面找到对应记录，点击编辑即可。

### Q: 初始体重是如何计算的？

A: 体重趋势图的起点取自：猫咪档案中记录的体重，或第一条养成时间线体重记录——以时间更早的那条为准。

### Q: 多猫对比支持几只猫？

A: 支持 2–5 只猫咪同时对比，涵盖体重趋势、健康状态、基本信息三个维度。在「我的猫咪」页面点击「📊 多猫对比」即可使用。
