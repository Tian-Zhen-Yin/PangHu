## 1. 背景与动机

现有产品手册停留在 V3.0（最新章节到 V3.2 多猫对比），未涉及任何 Agent 内容。与此同时，Agent 体系已陆续落地：

- **Memory 模块**已上线（feature flag `AGENT_CONTEXT_MEMORY` 默认开启）
- **AI Agent 核心系统**开发中（ReAct 多工具编排、SSE 流式、智能/普通双模式）
- **LLM Tool Calling Loop** 开发中（feature flag `LLM_TOOL_CALLING_LOOP`，双轨：V2.0 旧链路 vs V3.0 AgentLoop）
- **宠物陪玩 Pet Play Coach** 处于 PRD 阶段（MVP）
- **Agent 创新功能**（执行轨迹可视化、过敏追踪、健康周报）处于设计阶段

手册与产品现状脱节，需要更新。本设计规定如何将 Agent 内容纳入手册，并把叙事重构为 V4.0。

## 2. 设计约束（已与用户确认）

1. **范围策略**：重构为 V4.0，以 Agent 为核心叙事主线，原有功能作为 Agent 的数据/工具支撑呈现。
2. **目标读者**：偏终端用户（猫咪主人）。重点讲"能做什么/怎么用"，技术实现细节做减法。
3. **功能边界**：已上线/开发中功能详写；PRD/设计阶段功能（陪玩、过敏、周报）放入"即将推出"章节简述，并明确标注未上线。
4. **结构方案**：方案 B——Agent 独立大章节 + 原有成熟功能保留，每节以"与喵喵医生联动"小节串联主线。
5. **命名统一**：Agent 在手册中统一称 **"喵喵医生"**。

## 5. 各章节内容规格

### 第 1 章 产品概述

- **一句话定位**：改为"你的专属猫咪 AI 健康顾问"（强调 Agent）。
- **核心价值**（重排顺序，喵喵医生置顶）：
  1. 喵喵医生 AI 顾问：基于猫咪档案的多工具编排、执行可视化、多轮记忆
  2. 多猫咪管理：一个账户管理多只猫咪独立健康记录
  3. 体重健康可视化：趋势图表 + 品种健康标准 + 多猫对比
  4. 养护知识库：187 个知识块，涵盖疫苗、喂养、训练、健康等 20 个指南
  5. 成长时间线：记录每只猫咪的成长轨迹与健康变化
- **V4.0 更新亮点**（新增小节）：用 3–5 条要点对比 V3.0，突出 Agent。
- **功能架构图**（简化版）：保留用户界面层、AI 智能层（喵喵医生 + 工具）、数据层三档；**删除**原 API 服务层、应用状态层（Store/Auth）细节。

### 第 2 章 喵喵医生 · AI 智能顾问（全新核心章节）

| 小节 | 内容要点 |
|---|---|
| 2.1 喵喵医生是谁 | 定位：结合你的猫咪档案（品种、年龄、体重、疫苗、健康）提供个性化建议的 AI 顾问；说明与普通聊天机器人的差异（能调用工具读取你的实际数据） |
| 2.2 智能模式 vs 普通模式 | 用户可见的切换说明：智能模式=Agent 驱动，展示工具调用过程与结构化卡片；普通模式=传统简洁对话气泡。给出何时选哪种的指引 |
| 2.3 对话时你能看到什么 | 四要素通俗化描述：① 执行轨迹（意图→规划→执行→报告的流水线可视化，**不**宣称展示 LLM 推理过程）② 工具调用进度条 ③ 结构化摘要卡片（档案/健康评估/疫苗/知识）④ 引用来源（知识库指南，可点击跳转）。配 Agent 消息卡片 ASCII 示意图 |
| 2.4 喵喵医生记得你 | 多轮记忆的用户视角描述：记得上一句、基于你的猫咪档案个性化；**不**写 cache/Trace/confirmation TTL 等技术实现 |
| 2.5 常见对话示例 | 3 条示例问答："奶糖最近体重有变化吗？""它的疫苗该打了吗？""英短公猫正常体重是多少？"，每条标注会触发哪些工具卡片（用中文名，不用 `get_cat_info`） |

章末引导句：后续每章会标注该功能如何与喵喵医生联动。

## 7. 写作风格规范

- **Agent 称呼**：统一"喵喵医生"，不混用"AI医师/AI智能咨询/AI Agent 智能顾问"。
- **emoji**：适度使用，与现有手册一致（📊 🐱 ✅ 💉 📋 📐）。不过度堆砌。
- **语气**：亲切、清晰、诚实。避免技术黑话（"ReAct""SSE 流式""工具编排"→改为"一步步调用工具""实时显示""智能读取你的数据"）。
- **诚实性**：不夸大 Agent 能力。执行轨迹明确说明是"Agent 执行流水线的可视化"，**不**宣称展示 AI 的思考过程（与 [Agent创新功能设计.md](../../03-设计/Agent创新功能设计.md) V2.0 命名修订一致）。专业建议处标注"参考性建议，具体诊疗以兽医为准"。
- **未实现功能**：第 6 章每项强制标注"尚未上线"。
- **开发中功能措辞**：第 2 章的 Agent 核心能力（执行轨迹、工具卡片、多轮记忆、智能/普通模式）属于"开发中"，措辞上使用"喵喵医生支持 / 将展示"等表述，避免"你现在点击即可"式的强承诺。区分原则——**Agent 核心作为 V4.0 主线详写（第 2 章），因其是本轮重构的主体；陪玩/过敏/周报等扩展功能处于更早的 PRD/设计阶段，简写并归入第 6 章**。两者都非"已上线"，但详略程度由"是否为本轮主线"决定。
