# 哈吉咪养成计划 - 开发文档 V3.0

## 项目简介

哈吉咪养成计划是一个专注于猫咪养护的全栈Web应用，提供从幼猫到成年的全程陪伴式养护指导。项目采用前后端分离架构，使用现代化的技术栈构建。

**V3.0 更新**：新增体重趋势可视化图表（ECharts）、增强的认证初始化系统、完善的调试日志体系。

---

## 技术栈

### 前端
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **语言**: TypeScript
- **状态管理**: Pinia + pinia-plugin-persistedstate
- **路由**: Vue Router
- **UI组件库**: Element Plus
- **图表库**: ECharts 5.x
- **HTTP客户端**: Axios
- **Markdown渲染**: Marked + Highlight.js

### 后端
- **运行时**: Node.js
- **框架**: Express
- **语言**: TypeScript
- **数据库**: SQLite (开发环境)
- **ORM**: Prisma
- **认证**: JWT (jsonwebtoken)
- **密码加密**: bcryptjs
- **数据验证**: express-validator
- **AI服务**: 智谱AI GLM-4-flash
- **流式响应**: Server-Sent Events (SSE)

### 1. 体重趋势图表组件

#### 组件结构

**文件**：`frontend/src/components/cat/WeightTrend.vue`

```vue
<template>
  <div class="weight-trend">
    <div class="trend-header">
      <h3>体重趋势</h3>
      <span v-if="latestWeight" class="current-weight">
        当前体重: <strong>{{ latestWeight }}kg</strong>
      </span>
    </div>

    <!-- 加载状态 -->
    <div v-if="loading" class="loading">
      <LoadingSpinner />
    </div>

    <!-- 错误状态 -->
    <div v-else-if="error" class="error">
      <p>{{ error }}</p>
    </div>

    <!-- 空数据状态 -->
    <div v-else-if="weightHistory.length === 0" class="empty-state">
      <p>暂无体重记录</p>
      <p class="hint">添加成长记录时记录体重，即可查看趋势图</p>
    </div>

    <div v-else ref="chartRef" class="chart-container"></div>
  </div>

<script setup lang="ts">
import { ref, computed, onMounted, onUnmounted, watch, nextTick } from 'vue'
import * as echarts from 'echarts'
import type { EChartsOption } from 'echarts'

interface Props {
  catId: string
  catName?: string
}

const props = defineProps<Props>()

// 状态

const weightHistory = ref<WeightHistoryRecord[]>([])

const error = ref('')
let chart: echarts.ECharts | null = null

// 计算最新体重

  if (weightHistory.value.length === 0) return null
  return weightHistory.value[weightHistory.value.length - 1]?.weight.toFixed(1)
})

// 初始化图表
function initChart() {
  if (!chartRef.value) return

  // 销毁已存在的图表
  if (chart) {
    chart.dispose()
  }

  chart = echarts.init(chartRef.value)
  updateChart()
}

// 更新图表数据
function updateChart() {
  if (!chart || weightHistory.value.length === 0) return

  const dates = weightHistory.value.map(r => r.date)
  const weights = weightHistory.value.map(r => r.weight)

  const option: EChartsOption = {
    // ... ECharts 配置
  }

  chart.setOption(option)
}

// 获取体重历史数据
async function fetchWeightHistory() {
  loading.value = true
  error.value = ''

  try {
    const response = await getWeightHistory(props.catId)
    weightHistory.value = response.data || []

    // V3关键修复：先关闭loading，再等待DOM更新
    loading.value = false
    await nextTick()
    initChart()
  } catch (err: any) {
    error.value = err.message || '获取体重历史失败'
    loading.value = false
  }
}

  chart?.resize()
}

onMounted(() => {
  fetchWeightHistory()
  window.addEventListener('resize', handleResize)
})

onUnmounted(() => {
  chart?.dispose()
  window.removeEventListener('resize', handleResize)
})

// 监听 catId 变化
watch(() => props.catId, () => {
  fetchWeightHistory()
})
</script>

<style scoped>
.chart-container {
  width: 100%;
  height: 280px;
}
</style>
```

#### V3 关键修复：时序问题

**问题**：在 V2 版本中，图表不显示是因为：
1. `initChart()` 在 `loading.value = false` 之前调用
2. 此时 DOM 中图表容器还未渲染（v-if 条件不满足）
3. `chartRef.value` 为 null，ECharts 无法初始化

**解决方案**：
```typescript
// V2 错误顺序
try {
  weightHistory.value = response.data
  await nextTick()
  initChart()  // 此时 loading 还是 true！
} finally {
  loading.value = false  // 太晚了
}

// V3 正确顺序
try {
  weightHistory.value = response.data
  loading.value = false  // 先关闭 loading
  await nextTick()       // 等待 DOM 更新
  initChart()            // 现在 chartRef 存在了
} catch (err) {
  loading.value = false
}
```

#### 容器尺寸检查

为防止容器尺寸为 0 的情况，添加了检查和重试机制：

```typescript
function initChart() {
  if (!chartRef.value) return

  // 检查容器尺寸
  const rect = chartRef.value.getBoundingClientRect()
  if (rect.width === 0 || rect.height === 0) {
    // 延迟重试
    setTimeout(() => {
      if (chartRef.value) initChart()
    }, 100)
    return
  }

  chart = echarts.init(chartRef.value)
  updateChart()
}
```

#### Auth Store 初始化逻辑

**文件**：`frontend/src/stores/auth.ts`

```typescript
export const useAuthStore = defineStore('auth', () => {
  const token = ref<string | null>(null)
  const user = ref<User | null>(null)

  // 初始化认证状态
  function initAuth() {
    const savedToken = localStorage.getItem('auth_token')
    const savedUser = localStorage.getItem('auth_user')

    if (savedToken && savedUser) {
      token.value = savedToken
      user.value = JSON.parse(savedUser)

      // 异步验证 token 有效性
      fetchCurrentUser().catch(() => {
        // Token 无效，清除认证信息
        clearAuth()
      })
    }
  }

  // 获取当前用户
  async function fetchCurrentUser(): Promise<boolean> {
    if (!token.value) return false

    try {
      const response = await getCurrentUser()
      if (response.success && response.data) {
        user.value = response.data
        localStorage.setItem('auth_user', JSON.stringify(response.data))
        return true
      }
      clearAuth()
      return false
    } catch (err) {
      clearAuth()
      return false
    }
  }

  return { token, user, initAuth, fetchCurrentUser }
})
```

### 4. 体重历史数据服务

#### 后端服务实现

**文件**：`backend/src/services/cat.service.ts`

```typescript
// 获取猫咪体重历史记录（用于趋势图）
export async function getCatWeightHistory(catId: string, userId: string) {
  // 1. 验证猫咪存在且属于用户
  const cat = await prisma.cat.findFirst({
    where: { id: catId, userId, isActive: true }
  })

  if (!cat) return null

  // 2. 获取所有成长记录
  const allRecords = await prisma.petRecord.findMany({
    where: { catId },
    orderBy: { recordDate: 'asc' }
  })

  // 3. 过滤有体重的记录
  const records = allRecords
    .filter(r => r.weight !== null && r.weight !== undefined)
    .map(record => ({
      date: record.recordDate.toISOString().split('T')[0],
      weight: record.weight!,
      notes: record.notes
    }))

  // 4. 如果猫咪档案有初始体重，且没有更早记录，添加初始点
  if (cat.weight) {
    const hasEarlierRecord = records.length > 0 &&
      new Date(records[0].date) <= cat.createdAt

    if (!hasEarlierRecord) {
      records.unshift({
        date: cat.createdAt.toISOString().split('T')[0],
        weight: cat.weight,
        notes: '初始体重'
      })
    }
  }

  return records
}
```

function generateWeightRecords(userId: string, catId: string, cat: any) {
  const records = []
  const birthDate = new Date(cat.birthDate)
  const now = new Date()
  let recordDate = new Date(birthDate)
  recordDate.setDate(recordDate.getDate() + 56) // 从8周开始

  const baseWeight = cat.weight || 1.0
  const maxWeight = cat.gender === 'male' ? 6.0 : 5.0

  // 幼猫期（2-6月）每2周记录一次
  while (recordDate.getTime() < birthDate.getTime() + 180 * 24 * 60 * 60 * 1000) {
    const age = Math.floor((recordDate.getTime() - birthDate.getTime()) /
      (24 * 60 * 60 * 1000 * 7))
    const { ageWeeks, ageMonths } = calculateAge(birthDate, recordDate)

    baseWeight += 0.08 // 每周约增加80g

    records.push({
      userId,
      catId,
      petName: cat.name,
      recordDate: new Date(recordDate),
      weight: Math.min(baseWeight, maxWeight),
      ageWeeks,
      ageMonths,
      photoUrl: '',
      notes: `体重${baseWeight.toFixed(1)}kg，健康成长中`
    })

    recordDate.setDate(recordDate.getDate() + 14)
  }

  // 成年期（12月后）每月记录一次
  while (recordDate.getTime() < now.getTime()) {
    baseWeight += (Math.random() - 0.5) * 0.1
    const { ageWeeks, ageMonths } = calculateAge(birthDate, recordDate)

    records.push({
      userId,
      catId,
      petName: cat.name,
      recordDate: new Date(recordDate),
      weight: Math.max(3, Math.min(baseWeight, maxWeight)),
      ageWeeks,
      ageMonths,
      photoUrl: '',
      notes: '定期体检，健康状况良好'
    })

    recordDate.setMonth(recordDate.getMonth() + 1)
  }

  return records
}

### 常见问题排查

#### 图表不显示

1. **检查数据是否返回**
   ```
   [WeightTrend] weightHistory.length: 0
   ```
   → 表示没有体重记录，需要先添加

2. **检查容器尺寸**
   ```
   [WeightTrend] Chart container size: 0 x 0
   ```
   → 容器未渲染，检查 v-if 条件

3. **检查认证状态**
   ```
   [API Request] ... hasToken: false
   ```
   → 用户未登录，需要重新登录

#### API 调用失败

1. **401 错误**
   ```
   [API Error] 401 未提供认证令牌
   ```
   → Token 过期，重新登录

2. **404 错误**
   ```
   [API Error] 404 猫咪不存在
   ```
   → catId 错误或无权限访问
