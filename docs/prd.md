# 二、产品背景与目标
## 2.1 现状
- V3.0 已完成：多猫管理、AI咨询、体重趋势图、疫苗管理、完善技术架构
- 当前问题：
  1. 体重曲线**无健康标准**，仅展示变化，无专业判断
  2. 用户需主动打开，**无主动提醒**，留存偏低
  3. 功能偏工具理性，**缺少情感化内容**
  4. AI 仅被动问答，**无主动分析能力**
  5. 无商业化预埋，长期价值不清晰
  6. 成长线默认“从小养到大”，**不适配领养、半路接手、成年猫咪**，导致部分用户使用体验差、记录意愿下降
  7. 自由记录门槛高，**普通用户不知道该记录什么、如何记录**

## 2.2 版本目标
### V3.1 目标（工具强化 + 体验修复）
1. 让体重图表**具备专业健康判断能力**
2. 建立**主动提醒机制**，提升日活与留存
3. 支持**成长相册+图片记录**，增强情感连接
4. 支持**数据导出、体重目标**，完善工具闭环
5. 预埋**商业化基础字段与入口**
6. 优化成长线逻辑，**适配所有来源猫咪**（领养、成年、半路接手），修复核心体验痛点
7. 提供**系统轻量预设模板**，降低记录门槛，让新手用户也能快速标准化记录

### V3.2 目标（智能升级）
1. AI 从**被动问答 → 主动健康建议**
2. 支持**多猫体重对比**
3. 提供**体重异常智能预警**
4. 输出**个性化营养与喂养方案**

# 三、全局说明
## 3.1 术语定义
- 哈吉咪：猫咪昵称，产品IP
- 体重标准库：按品种/年龄/性别/绝育状态的猫咪体重参考范围
- 主动AI：基于用户数据自动生成建议，而非用户提问才回答
- 提醒规则：后台配置的触发条件与推送策略
- 会员标识：用于区分免费/付费用户的字段
- 饲养起始点：用户开始饲养猫咪的日期（区别于猫咪出生日期）
- 成长线适配：根据猫咪来源（从小养、领养、成年）调整成长记录的展示逻辑
- 轻量预设模板：系统内置固定记录模板，用户不可修改/新增/删除，仅快速选择使用

## 3.2 角色权限
- 游客：仅预览，无法使用核心功能
- 登录用户：可使用基础功能（档案、记录、基础图表、AI咨询、成长线适配、预设模板）
- 会员用户（未来）：可使用高级分析、多猫对比、报告导出等

# 模块一：体重健康标准库（V3.1 P0）
## 1.1 功能描述
- 内置猫咪体重标准参考库
- 自动匹配猫咪信息，判断**偏瘦 / 标准 / 超重**
- 在体重趋势图中叠加**标准区间阴影**

## 1.2 业务规则
1. 匹配维度：品种、月龄、性别、是否绝育
2. 标准来源：宠物临床通用数据 + 权威机构参考值
3. 若品种无标准，使用**家猫通用标准**
4. 若猫咪为领养/成年、无准确月龄，按“成年猫通用标准”匹配

## 1.3 UI 展示
1. 图表顶部展示结论：
   - 体重正常
   - 轻微偏瘦｜建议增加营养
   - 轻微超重｜建议控制饮食
2. 图表区域叠加**灰色半透明标准区间**
3. 悬停提示显示：日期、体重、是否在标准范围内

## 1.4 数据结构扩展
```typescript
interface WeightStandard {
  breed: string;
  ageMonth: number;
  gender: 'male' | 'female';
  neutered: boolean;
  minWeight: number;
  maxWeight: number;
}

interface WeightAnalysis {
  status: 'thin' | 'normal' | 'overweight';
  message: string;
  current: number;
  min: number;
  max: number;
}
```

## 1.5 验收标准（AC）
- 猫咪档案修改后，体重结论**自动刷新**
- 标准区间与体重曲线**正确叠加**
- 无标准品种自动使用**通用标准**
- 领养/成年猫咪无准确月龄时，自动匹配成年猫通用标准
- 数据不足时显示“数据较少，暂无法判断”

# 模块二：智能提醒与通知系统（V3.1 P0）
## 2.1 功能描述
建立全场景提醒体系，包括：疫苗到期、驱虫、体检、体重异常、每周记录提醒，适配所有来源猫咪（无历史疫苗/体重数据时不强制提醒）。

## 2.2 提醒类型
1. **疫苗提醒**：到期前 7/3/1 天提醒
2. **驱虫提醒**：支持按月/季度/半年周期
3. **体检提醒**：年度/半年体检提醒
4. **体重异常提醒**：短期下降/上升超阈值
5. **记录提醒**：每周固定时间提醒记录体重

## 2.3 实现方式
- 后端：定时任务 + 消息表
- 前端：App角标 + 首页消息中心 + 本地推送
- 设置页：总开关、时段开关、静音时段

## 2.4 验收标准
- 提醒时间准确，不重复推送
- 开关可正常关闭/开启
- 已完成事项自动停止提醒
- 领养/无历史数据的猫咪，不触发无意义的到期提醒
- 消息中心可标记已读/清空

# 模块三：成长相册与图片记录（V3.1 P1）
## 3.1 功能描述
每条成长记录支持上传图片，形成**图文成长时间线**，并在猫咪详情页展示封面，适配所有来源猫咪。

## 3.2 功能点
1. 新增/编辑记录可上传 1~9 张图
2. 养成时间线以**图片+文字+数据**卡片展示
3. 猫咪详情页展示最新照片作为封面
4. 支持查看按月归档的成长相册
5. 领养猫咪的第一条记录，可标记“领养当天”

## 3.3 约束
- 单张图片 ≤ 10MB
- 自动生成缩略图

## 3.4 验收标准
- 图片上传/删除/预览正常
- 时间线按时间倒序排列
- 更换照片后封面同步更新
- 弱网环境不崩溃

# 模块四：适配领养/半路接手猫咪：成长线灵活化改造（V3.1 P0）
## 4.1 功能描述
优化成长线展示逻辑，不再强制“从猫咪出生开始记录”，而是以**用户开始饲养日期**为起始点，适配领养、半路接手、成年、年龄不详的猫咪。

## 4.2 业务规则
1. 猫咪来源分类：
   - 从小养到大
   - 领养（幼年）
   - 领养（成年）
   - 年龄不详
2. 时间线只展示：**开始饲养日期 → 今天**
3. 生日可填：未知/估算
4. 体重曲线起点 = 第一次记录，不虚拟历史数据

## 4.3 数据结构扩展
```typescript
interface Cat {
  // ...原有字段
  adoptStatus: 'raisedFromBaby' | 'adoptedYoung' | 'adoptedAdult' | 'unknownAge';
  startRaisedDate: string;
  birthDateEstimated: boolean;
  birthDate: string | null;
}
```

## 4.4 UI 展示
- 档案页：选择来源 → 自动显示对应年龄文案
- 时间线标题：成长记录 / 领养后成长记录 / 饲养记录
- 无记录时显示温和引导文案

## 4.5 验收标准（AC）
- 任意来源猫咪都能自然展示时间线与图表
- 无历史数据不空白、不报错
- AI 不追问不存在的幼猫信息
- 切换来源不丢失已有数据

# 模块五：成长记录·轻量预设模板（V3.1 P1）
## 5.1 需求定位
**功能名称**：成长记录·轻量预设模板
**优先级**：P1
**决策结论**：
**只做系统内置轻量预设模板，不做自定义、不做社区、不做复杂计划。**

## 5.2 需求背景
1. 大部分用户**没有养护计划能力**，不知道该记录什么
2. 复杂模板开发成本高、使用率低
3. 当前目标是**降低记录门槛**，而非提供强大工具
4. 适配所有猫咪来源，不强制幼猫流程

## 5.3 功能描述
提供**4 种系统固定模板**，覆盖 95% 日常场景：
1. **日常记录**：体重、饮食、精神、备注
2. **疫苗接种**：疫苗名、日期、到期日、医院
3. **驱虫记录**：体内/体外、日期、下次日期
4. **体检记录**：体检日期、项目、结果、医生建议

### 规则：
- 模板**系统内置**，用户不可增删改
- 点击模板 → 自动带出固定字段
- 提交后生成一条标准成长记录
- 保留原有自由记录能力

## 5.4 界面交互
1. 进入「添加记录」
2. 顶部展示横向标签：
   日常记录 | 疫苗 | 驱虫 | 体检
3. 点击模板 → 展示对应字段表单
4. 填写 → 保存 → 回到时间线

## 5.5 数据结构（极轻）
```typescript
interface PetRecord {
  // 原有字段
  type: 'daily' | 'vaccine' | 'deworm' | 'healthCheck';
}
```

## 5.6 验收标准（AC）
- 4 个模板可正常点击、切换、填写、保存
- 每个模板字段正确、必填项合理
- 提交后在时间线正常展示对应类型卡片
- 不影响原有自由记录功能
- 无自定义模板入口、无复杂配置
- 所有猫咪来源均可正常使用

# 模块六：AI 主动健康建议（V3.2 P0）
## 6.1 功能描述
AI 自动读取猫咪档案、体重、疫苗、来源，生成**结构化健康建议**，适配所有猫咪。

## 6.2 输出场景
- 体重分析 → 喂养建议
- 疫苗/驱虫/体检 → 阶段计划
- 来源适配：从小养 / 领养幼年 / 领养成年 / 年龄不详

## 6.3 展示位置
- 首页：AI 今日建议
- 猫咪详情：健康总结
- 体重图表下方：AI 解读

## 6.4 验收标准
- 猫咪信息变化后建议自动刷新
- 内容专业、可读、无医疗诊断结论
- 适配所有来源，不出现不符合场景的建议
- 响应时间 < 3s
