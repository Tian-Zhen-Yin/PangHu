# 二、产品背景与目标
## 2.1 现状
- V3.0 已完成：多猫管理、AI咨询、体重趋势图、疫苗管理、完善技术架构
- 当前问题：
  1. 体重曲线**无健康标准**，仅展示变化，无专业判断
  2. 用户需主动打开，**无主动提醒**，留存偏低
  3. 功能偏工具理性，**缺少情感化内容**
  4. AI 仅被动问答，**无主动分析能力**
  5. 无商业化预埋，长期价值不清晰

## 2.2 版本目标
### V3.1 目标（工具强化）
1. 让体重图表**具备专业健康判断能力**
2. 建立**主动提醒机制**，提升日活与留存
3. 支持**成长相册+图片记录**，增强情感连接
4. 支持**数据导出、体重目标**，完善工具闭环
5. 预埋**商业化基础字段与入口**

### V3.2 目标（智能升级）
1. AI 从**被动问答 → 主动健康建议**
2. 支持**多猫体重对比**
3. 提供**体重异常智能预警**
4. 输出**个性化营养与喂养方案**

# 三、全局说明
## 3.1 术语定义
- **哈吉咪**：猫咪昵称，产品IP
- **体重标准库**：按品种/年龄/性别/绝育状态的猫咪体重参考范围
- **主动AI**：基于用户数据自动生成建议，而非用户提问才回答
- **提醒规则**：后台配置的触发条件与推送策略
- **会员标识**：用于区分免费/付费用户的字段

## 3.2 角色权限
- 游客：仅预览，无法使用核心功能
- 登录用户：可使用基础功能（档案、记录、基础图表、AI咨询）
- 会员用户（未来）：可使用高级分析、多猫对比、报告导出等

## 模块一：体重健康标准库（V3.1 P0）
### 1.1 功能描述
- 内置猫咪体重标准参考库
- 自动匹配猫咪信息，判断**偏瘦 / 标准 / 超重**
- 在体重趋势图中叠加**标准区间阴影**

### 1.2 业务规则
1. 匹配维度：
   - 品种
   - 月龄（精确到月）
   - 性别
   - 是否绝育
2. 标准来源：宠物临床通用数据 + 权威机构参考值
3. 若品种无标准，使用**家猫通用标准**

### 1.3 UI 展示
1. 图表顶部展示结论：
   - 体重正常
   - 轻微偏瘦｜建议增加营养
   - 轻微超重｜建议控制饮食
2. 图表区域叠加**灰色半透明标准区间**
3. 悬停提示显示：日期、体重、是否在标准范围内

### 1.4 数据结构扩展
```typescript
interface WeightStandard {
  breed: string;           // 品种
  ageMonth: number;        // 月龄
  gender: 'male' | 'female';
  neutered: boolean;
  minWeight: number;       // 最低标准
  maxWeight: number;       // 最高标准
}

interface WeightAnalysis {
  status: 'thin' | 'normal' | 'overweight';
  message: string;
  current: number;
  min: number;
  max: number;
}
```

### 1.5 验收标准（AC）
- 猫咪档案修改后，体重结论**自动刷新**
- 标准区间与体重曲线**正确叠加**
- 无标准品种自动使用**通用标准**
- 数据不足时显示“数据较少，暂无法判断”

## 模块二：智能提醒与通知系统（V3.1 P0）
### 2.1 功能描述
建立全场景提醒体系，包括：疫苗到期、驱虫、体检、体重异常、每周记录提醒。

### 2.2 提醒类型
1. **疫苗提醒**
   - 到期前 7/3/1 天提醒
2. **驱虫提醒**
   - 支持按月/季度/半年周期
3. **体检提醒**
   - 年度/半年体检提醒
4. **体重异常提醒**
   - 短期下降/上升超阈值
5. **记录提醒**
   - 每周固定时间提醒记录体重

### 2.3 实现方式
- 后端：定时任务 + 消息表
- 前端：App角标 + 首页消息中心 + 本地推送
- 设置页：总开关、时段开关、静音时段

### 2.4 验收标准
- 提醒时间准确，不重复推送
- 开关可正常关闭/开启
- 已完成事项自动停止提醒
- 消息中心可标记已读/清空

## 模块三：成长相册与图片记录（V3.1 P1）
### 3.1 功能描述
每条成长记录支持上传图片，形成**图文成长时间线**，并在猫咪详情页展示封面。

### 3.2 功能点
1. 新增/编辑记录可上传 1~9 张图
2. 养成时间线以**图片+文字+数据**卡片展示
3. 猫咪详情页展示最新照片作为封面
4. 支持查看按月归档的成长相册

### 3.3 约束
- 单张图片 ≤ 10MB
- 保留缩略图，避免加载过慢

### 3.4 验收标准
- 图片上传/删除/预览正常
- 时间线按时间倒序排列
- 更换照片后封面同步更新
- 弱网环境不崩溃

---

## 模块四：AI 主动健康建议（V3.2 P0）
### 4.1 功能描述
AI 不再只等用户提问，而是**自动读取猫咪档案、体重、疫苗、年龄**，生成结构化健康建议。

### 4.2 输出场景
1. 体重分析：偏瘦/正常/超重 → 喂养建议
2. 疫苗/驱虫/体检 → 下一阶段计划
3. 年龄阶段：幼猫/成猫/老年 → 专属养护要点

### 4.3 展示位置
- 首页：AI 今日建议
- 猫咪详情：健康总结
- 体重图表下方：AI 解读

### 4.4 验收标准
- 猫咪信息变化后，建议**自动刷新**
- 输出内容专业、可读、不吓人
- 不出现医疗诊断结论，仅为养护建议
- 响应时间 < 3 秒

---

## 模块五：数据导出与体重目标（V3.1 P1）
### 5.1 数据导出
- 导出体重历史为 CSV
- 导出健康报告为图片/PDF
- 文件名：猫咪名_导出日期_报告类型

### 5.2 体重目标
- 用户可设置目标体重 & 目标日期
- 图表展示目标线
- 显示距离目标还差多少

### 5.3 验收标准
- 导出文件可正常打开
- 数据与App内一致
- 目标修改后图表实时更新

## 模块六：商业化基础预埋（V3.1 P1）
### 6.1 功能描述
不做付费功能，仅**预埋字段、入口、权限位**，为后续会员、广告、服务做准备。

### 6.2 预埋内容
1. 用户表增加：
   - 会员类型
   - 会员过期时间
2. 全局权限控制逻辑
3. 首页预留推荐位（可开关）
4. 高级功能入口（置灰，提示“即将上线”）

### 6.3 验收标准
- 字段可正常读写
- 权限逻辑不影响现有功能
- 推荐位可后台开关
- 无视觉干扰
