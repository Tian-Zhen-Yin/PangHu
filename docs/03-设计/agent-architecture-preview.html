二、Pipeline 六阶段时间线

1️⃣
Router
意图分类，命中关键词模式匹配
2️⃣
Planner
构建 PlanStep[] 工具计划
3️⃣
Loop
LLM tool-calling 循环（V3.0）
4️⃣
Executor
工具执行 + 超时 + 重试
5️⃣
Reporter
生成自然语言报告
6️⃣
Stream
SSE 推送到前端
🎯

阶段 1 · 意图路由 (AgentRouter)

1
正则关键词匹配
10+ 组关键词字典：greeting / cat_info / health / vaccine / weight / allergy / report
2
密度评分
matchChars / message.length 算 confidence
3
返回 IntentResult
{ intent, confidence }
📋

阶段 2 · 计划构建 (AgentPlanner)

1
基于意图选工具
switch(intent) → 添加对应 PlanStep
2
动态扩展
根据消息关键词（疫苗/趋势）追加步骤
3
策略类型
noop / single_tool / multi_tool / rag_fallback
🔄

阶段 3 · LLM 循环 (AgentLoop) V3

1
注入工具定义
5 个 readonly 工具的 JSON Schema
2
LLM 决定调用
模型自主选择工具 + 参数
3
多轮迭代
maxIterations=5，防止死循环
⚡

阶段 4 · 工具执行 (AgentExecutor)

1
超时控制
AGENT_TOOL_TIMEOUT_MS=5000
2
错误重试
MAX_RETRIES=2，识别瞬时故障
3
执行追踪
ExecutionTracer 记录每步结果
📝

阶段 5 · 报告生成 (AgentReporter)

1
工具结果汇总
遍历 ToolResult[] → 模板化输出
2
特殊工具过滤
health_report 卡片优先，文字为空
3
LLM 复述（可选）
report.length<2000 时调 LLM 自然化
📡

阶段 6 · SSE 流式推送

1
事件类型
meta / content / tool / trace / done / error
2
实时推送
res.write() 流式输出 token
3
持久化
metadata 存 toolCalls 含 output

三、消息状态机

pending

→
streaming

→
tool-running

→

→
