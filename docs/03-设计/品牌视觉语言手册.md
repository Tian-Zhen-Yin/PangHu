## 二、 首页深度重构：双栏沉浸式布局

### 2.1 品牌导航锚定 (Header Branding)

* **规范**: 将 `default` 表情插画嵌入 Logo 区，高度严格限制在 **32px**，确保与品牌文字视觉水平对齐。

### 2.2 金刚区“破形”设计 (Action Grid)

* **视觉高亮**: 每个功能按钮配置专属马卡龙色底座（如：记录-浅橙、体重-浅蓝）。
* **破形动效**: 插画高度设为容器的 **130%**，让胖虎头部略微冲出背景圆圈，增强灵动感。

### 2.3 复合式最近记录模块 (Recent Record Group)

采用 **5:7 黄金比例** 左右双联布局，彻底消除信息单薄感。

#### A. 左栏：智能趋势看板 (Dashboard Pane)

* **WeightSparkline**: 使用 SVG 绘制平滑曲线，配合 `--color-primary-light` 渐变填充。
* **AI 寄语区**: 在卡片底部增加胖虎头像与动态对话泡，基于数据波动自动生成语义化文案（如：“奶糖最近长肉很快哦！”）。

#### B. 右栏：叙事时间轴 (Trajectory Timeline)

* **轴线规范**: 采用垂直线串联，最新的节点使用 `--color-primary` 并带有呼吸扩散光圈。
* **数据卡片**: 每一条记录包含体重绝对值、环比增量（如 `+0.24kg`）及情绪小标签。

## 三、 跨组件联动交互逻辑 (Cross-Component Interaction)

本规范定义了“点哪看哪”的流畅数据追踪体验：

1. **触发同步**: 点击左侧趋势图上的数据锚点时，右侧 `TrajectoryList` 自动执行 `scrollIntoView` 平滑滚动至对应记录。
2. **状态高亮**: 激活的记录卡片触发 `is-active` 样式：边框变色、背景高亮，且卡片内的胖虎执行 `bounce` 弹跳动画。
3. **情感反馈**: 底部 AI 寄语区的胖虎表情随选中点的数据表现实时切换（增长良好对应 `excited`，下降对应 `confused`）。

## 四、 全局视觉与色彩规范

### 4.1 全局 CSS 变量 (奶油色系)

```css
:root {
  --color-primary: #F4A261;         /* 主色：暖橘 */
  --color-primary-light: #FDF3E9;   /* 激活背景色 */
  --color-text-main: #5C544E;       /* 标题深咖色 */
  --color-bg-app: #FAF8F5;          /* 页面底色 */
  
  /* 阴影规格 */
  --shadow-sm: 0 8px 16px rgba(0, 0, 0, 0.04);
  --shadow-md: 0 12px 24px rgba(244, 162, 97, 0.12);
}

```

### 4.2 动效规范

* **Spring Animation**: 按钮点击采用 `cubic-bezier(0.175, 0.885, 0.32, 1.275)` 物理回弹。
* **Ripple Effect**: 时间轴节点激活时，产生 4px 向外扩散的微光效果。
