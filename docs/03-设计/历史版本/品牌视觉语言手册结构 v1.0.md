# 🐱 品牌主视觉方向说明 v1.0（AI 可执行版）

---

# 0️⃣ 品牌核心定义

## 品牌类型

宠物陪伴型记录 App

## 品牌气质

温柔 / 柔软 / 奶油色 / 安静 / 治愈 / 生活感

## 禁止气质

冷科技 / 商务后台 / 极简冷淡风 / 强数据工具感

---

# 1️⃣ 主视觉目标

生成用于以下场景：

* 官网首屏
* App 启动页
* Dashboard 顶部 Banner
* 应用商店截图背景
* 品牌宣传图

视觉必须传达：

> “陪伴猫咪成长的温柔记录空间”

---

# 2️⃣ 视觉风格参数（AI 必须遵守）

## 2.1 色彩参数

主色范围：

* 暖橙：#F6B26B ± 8%
* 奶油背景：#FAF8F5 ± 5%
* 健康绿：#9ED5B8 ± 10%
* 点缀粉：#F8C8DC ± 10%

色彩比例：

* 背景 60%
* 主色 30%
* 点缀 10%

禁止：

* 高饱和红
* 深灰黑背景
* 冷蓝主色

---

# 3️⃣ 构图规范

## 3.1 构图类型

主视觉采用：

* 居中式构图
* 卡片浮层结构
* 大留白
* 柔光背景

不允许：

* 多元素杂乱拼贴
* 强透视空间
* 科技感线条

---

## 3.2 画面结构模板

标准结构：

```
[柔和奶油渐变背景]

        🐱 猫咪角色（居中或略偏右）

[柔光卡片 UI 浮层]
    - 当前体重
    - 今日记录
    - 小图表

[轻装饰元素]
    - 猫爪印
    - 小星星
```

---

# 4️⃣ 插画风格规范

## 4.1 猫咪角色风格

* 扁平
* 圆润
* 线条圆角
* 不写实
* 表情温柔
* 不夸张卡通

姿态建议：

* 坐姿
* 侧躺
* 轻微抬头

禁止：

* 写实毛发
* 过度动漫风
* 夸张 Q 版比例

---

## 4.2 背景风格

* 奶油渐变
* 柔光斑
* 轻微噪点纹理

不允许：

* 科技网格
* 线性背景图案
* 几何硬块

---

# 5️⃣ 光影系统

光源设定：

* 柔和顶部光
* 暖色阴影
* 低对比

阴影参数（生成时参考）：

* 模糊 30-60
* 透明度 10-20%
* 偏暖色

---

# 6️⃣ 情绪表达目标

主视觉必须让用户感受到：

* 安心
* 亲密
* 被陪伴
* 记录生活

不是：

* 数据分析
* 管理效率
* 严肃工具

---

# 7️⃣ UI 浮层规范

主视觉中的 UI 元素必须：

* 使用圆角 20px+
* 白色卡片
* 轻阴影
* 橙色按钮

示例内容结构：

```
🐾 花花
今日体重 4.2kg
最近记录 · 2 条
[查看详情]
```

---

# 8️⃣ 动态主视觉（可选）

如果生成动效版本：

* 猫咪轻微呼吸
* 卡片微浮动
* 光晕缓慢扩散

节奏：

* 3~5 秒循环
* ease-in-out

# 🔟 品牌视觉一致性规则

AI 在生成任何视觉素材时必须保证：

1. 主色不偏离橙系
2. 不使用冷蓝科技元素
3. 圆角统一
4. 保持大留白
5. 不堆砌装饰元素
