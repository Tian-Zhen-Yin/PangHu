# 胖虎吉祥物视觉系统开发文档

> **子模块:** 成长记录页 (Growth Record)
> **版本:** v2.5 (里程碑视觉重构版)
> **设计目标:** 彻底剔除系统原生 Emoji，将首页的“奶油风”与“胖虎情感反馈”无缝延展至阶段导览与里程碑卡片中。

---

## 一、 全局容器与导航重构 (Layout & Navigation)

### 1.1 页面头部与宠物切换器 (Header & Selector)

* **视觉痛点**: 原生 🐱 Emoji 缺乏品牌感，下拉框边框生硬。
* **重构规范**:
* 标题图标：使用 `MascotCharacter` 的 `default` (微笑) 表情，尺寸 `xs` (24px)。
* 宠物切换器：改为**无边框胶囊样式 (Pill)**。底色使用 `--color-primary-light` (奶油浅橘)，文字使用 `--color-primary-dark`，点击时产生轻微缩放 (`scale: 0.95`)。



### 1.2 左侧阶段时间轴 (Stage Timeline Sidebar)

* **视觉痛点**: 独立的数字方块缺乏“成长连贯性”，选中态（粗边框）过于生硬。
* **重构规范**:
* **贯穿轴线**: 在所有数字节点背后，绘制一条垂直的 `--color-primary-light` 浅色轨迹线，将“新生期”到“成年期”串联。
* **状态区分**:
* `Active` (当前阶段)：纯色填充 `background: var(--color-primary)`，文字反白，移除所有 border，并增加 `--shadow-sm` 阴影。
* `Inactive` (其他阶段)：浅灰底色 `background: var(--color-bg-app)`，深咖色文字 `--color-text-muted`。





---

## 二、 核心信息区视觉规范 (Main Content Area)

### 2.1 悬浮式分段选项卡 (Segmented Pill Tabs)

* **视觉痛点**: 底部横线样式带有强烈的传统后台 B 端感，且 Emoji（📊✅💉📸）打乱了界面的色彩纯净度。
* **重构规范**:
* **容器**: 采用类似 iOS 的分段控制器布局，整体背景为 `--color-bg-app`，圆角 `100px`。
* **滑块**: 选中的 Tab 拥有白色背景 (`#FFF`) 和极浅的阴影 (`--shadow-xs`)。
* **图标**: 全面禁用 Emoji。替换为统一粗细的单色/双色扁平 SVG 图标（如：深咖色线条 + 少量暖橘色点缀）。



### 2.2 胖虎融合：里程碑卡片 (Milestone Cards)

这是本页面的视觉高光区域，我们将复用首页的**“内嵌式破形”**与**“马卡龙底色”**逻辑。

* **底色分配**: 不同的里程碑分配柔和的专属底色（提取自 v2.1 定义的 `--color-action-xxx` 变量）。
* **情感注入**: 移除 👀 和 👂，在卡片右侧嵌入特定表情的小尺寸胖虎（`size="sm"`）。
* **标签规范**: 周数标签（如“1周”）采用实心白色背景，圆角拉满。

### 2.3 交互式任务列表 (Interactive Task List)

* **视觉痛点**: 灰色长条卡片显得压抑，像是不可点击的禁用状态。
* **重构规范**:
* **卡片化**: 改为纯白底色 (`#FFF`) 卡片，默认无阴影，圆角 `16px`。
* **Hover 动效**: 悬停时背景泛起微弱奶油色，同时卡片上浮 `transform: translateY(-2px)`，伴随 `--shadow-sm`。
* **前缀图标**: 使用定制的“胖虎爪印”或精致的圆环 Checkbox，取代 🧼 等 Emoji。

### 3.2 悬浮式分段选项卡 (SegmentedTabs.vue)

通过相对定位的容器与绝对定位的“滑块（Indicator）”，实现类似 iOS 的平滑物理过渡效果。支持双向绑定 (`v-model`)。

```vue
<template>
  <div class="segmented-tabs-container">
    <div 
      class="tab-indicator" 
      :style="{ 
        transform: `translateX(${activeIndex * 100}%)`,
        width: `${100 / tabs.length}%` 
      }"
    ></div>

    <button
      v-for="(tab, index) in tabs"
      :key="tab.id"
      class="tab-btn"
      :class="{ 'is-active': activeIndex === index }"
      @click="handleTabClick(index, tab.id)"
    >
      <component v-if="tab.icon" :is="tab.icon" class="tab-icon" />
      <span class="tab-label">{{ tab.label }}</span>
      
      <span v-if="tab.badge" class="tab-badge" :class="tab.badgeType">{{ tab.badge }}</span>
    </button>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue';

interface TabItem {
  id: string;
  label: string;
  icon?: any; // 传入 Vue SVG 组件
  badge?: string | number;
  badgeType?: 'primary' | 'warning';
}

const props = defineProps<{
  tabs: TabItem[];
  modelValue: string; // 当前选中的 tab.id
}>();

const emit = defineEmits(['update:modelValue', 'change']);

// 计算当前激活的索引，用于驱动物理滑块的位置
const activeIndex = computed(() => {
  const index = props.tabs.findIndex(t => t.id === props.modelValue);
  return index === -1 ? 0 : index;
});

const handleTabClick = (index: number, id: string) => {
  emit('update:modelValue', id);
  emit('change', id);
};
</script>

<style scoped>
.segmented-tabs-container {
  position: relative;
  display: flex;
  align-items: center;
  background-color: var(--color-bg-app); /* 浅灰底色 */
  border-radius: 100px; /* 胶囊圆角 */
  padding: 4px;
  width: 100%;
  margin-bottom: 24px;
  user-select: none;
}

/* 核心：绝对定位的滑动白底 */
.tab-indicator {
  position: absolute;
  top: 4px;
  left: 4px; /* 补偿容器的 padding */
  height: calc(100% - 8px);
  background-color: #FFFFFF;
  border-radius: 100px;
  /* 加入轻微投影，使其产生悬浮感 */
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.04), 0 1px 2px rgba(0, 0, 0, 0.02);
  /* 使用 cubic-bezier 曲线实现丝滑弹簧效果 */
  transition: transform 0.3s cubic-bezier(0.25, 1, 0.5, 1);
  z-index: 1;
}

.tab-btn {
  flex: 1;
  position: relative;
  z-index: 2; /* 确保文字在滑块之上 */
  display: flex;
  align-items: center;
  justify-content: center;
  gap: 6px;
  padding: 10px 0;
  background: transparent;
  border: none;
  border-radius: 100px;
  cursor: pointer;
  font-size: 14px;
  font-weight: 500;
  color: var(--color-text-muted); /* 未选中时为浅灰 */
  transition: color 0.3s ease;
  -webkit-tap-highlight-color: transparent;
}

.tab-icon {
  width: 16px;
  height: 16px;
  fill: currentColor;
  transition: transform 0.2s ease;
}

/* 选中态样式：字体变色加粗 */
.tab-btn.is-active {
  color: var(--color-text-main);
  font-weight: 600;
}

/* 选中态图标微动效 */
.tab-btn.is-active .tab-icon {
  transform: scale(1.1);
  color: var(--color-primary-dark);
}

/* 可选：右上角的通知微标 */
.tab-badge {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  min-width: 16px;
  height: 16px;
  padding: 0 4px;
  border-radius: 100px;
  font-size: 10px;
  font-weight: 700;
  color: #FFF;
  background: var(--color-text-muted);
}
.tab-badge.warning { background: var(--color-primary); }
</style>

```

### 3.3 阶段时间轴侧边栏 (StageTimeline.vue)

通过 Flexbox 布局实现左侧贯穿轴线与右侧卡片的完美对齐。利用动态 Class 控制选中态，去除了原本的硬边框，改用纯净的阴影与色彩对比来彰显层级。

```vue
<template>
  <div class="stage-timeline-sidebar">
    <div 
      v-for="(stage, index) in stages" 
      :key="stage.id"
      class="timeline-node-wrapper"
      :class="{ 'is-active': modelValue === stage.id }"
      @click="handleStageSelect(stage.id)"
    >
      <div class="axis-column">
        <div class="node-circle">{{ index + 1 }}</div>
        <div v-if="index !== stages.length - 1" class="connecting-line"></div>
      </div>
      
      <div class="stage-content-card">
        <h5 class="stage-name">{{ stage.name }}</h5>
        <span class="stage-duration">{{ stage.duration }}</span>
      </div>
    </div>
  </div>
</template>

<script setup lang="ts">
export interface GrowthStage {
  id: string;
  name: string;
  duration: string;
}

const props = defineProps<{
  stages: GrowthStage[];
  modelValue: string; // 当前选中的阶段 ID (v-model)
}>();

const emit = defineEmits(['update:modelValue', 'change']);

const handleStageSelect = (id: string) => {
  if (props.modelValue !== id) {
    emit('update:modelValue', id);
    emit('change', id);
  }
};
</script>

<style scoped>
.stage-timeline-sidebar {
  display: flex;
  flex-direction: column;
  width: 100%;
  /* 移除原设计中生硬的外部大边框，保持左侧清爽 */

  transition: transform 0.2s ease;
}

}

/* ================= 轴线系统 ================= */

  flex-shrink: 0;

.node-circle {

.stage-name {

/* ================= 激活态核心视觉 (Active State) ================= */
```
