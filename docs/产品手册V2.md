# 哈吉咪养成计划 - 产品手册 V2.0

## 产品概述

**哈吉咪养成计划**是一款智能猫咪健康管理应用，结合了AI技术、RAG知识库检索和个性化档案管理，为猫咪主人提供全方位的养护指导。

### 核心价值

- **多猫咪管理**：一个账户管理多只猫咪档案，每只猫独立的健康记录
- **AI智能咨询**：根据猫咪的具体情况（年龄、体重、疫苗、健康状况）提供个性化建议
- **养护知识库**：187个知识块，涵盖疫苗、喂养、训练、健康等20个指南
- **成长时间线**：记录每只猫咪的成长轨迹和健康变化

## V2.0 新功能

### 1. 多猫咪档案系统

用户现在可以为一个账户创建多只猫咪档案，每只档案包含：

#### 基本信息
- 猫咪名字、头像
- 品种、性别、毛色
- 出生日期、领养日期
- 特征描述

#### 健康信息
- 当前体重
- 绝育状态及日期
- 过敏信息
- 既往病史

#### 关联数据
- 成长记录（独立于其他猫咪）
- 疫苗接种记录
- 历史咨询对话

### 2. 疫苗管理系统

全新的疫苗记录管理功能：

- **疫苗档案**：记录疫苗名称、类型、生产厂家、批号
- **接种记录**：接种日期、医生、诊所
- **智能提醒**：自动识别即将到期（30天内）的疫苗
- **反应记录**：记录接种后的不良反应

#### 支持的疫苗类型

| 类型 | 说明 | 推荐接种时间 |
|------|------|--------------|
| 猫三联 | 防护猫瘟、猫鼻支、猫杯状 | 6-8周龄开始，共3针 |
| 狂犬疫苗 | 防护狂犬病 | 3月龄以上，每年1次 |
| 猫传染性腹膜炎 | 防护FIP | 风险环境接种 |
| 其他 | 自定义疫苗类型 | - |

### 3. AI上下文增强

AI医师现在能理解当前咨询的猫咪档案：

```
💬 正在为「喵喵」提供咨询 (2岁3个月 · 公猫 · 5.2kg · 已绝育)
```

AI系统自动获取：
- 猫咪的基本信息（年龄、品种、性别）
- 健康状况（体重、绝育状态、过敏史）
- 最近的疫苗记录
- 最新的成长记录

**个性化回答示例**：

> 用户：我的猫咪最近不爱吃东西，怎么办？
>
> AI：看到「喵喵」是2岁3个月的公猫，体重5.2kg，这个体重属于正常范围。根据他的年龄阶段，我建议：
> 1. 首先检查是否到了绝育后的恢复期（我看到他已经绝育）
> 2. 最近一次疫苗是狂犬疫苗（2025-12-01），排除疫苗反应
> 3. 2岁正值成年期活跃阶段，食欲下降可能与...

## 用户指南

### 添加第一只猫咪

1. 登录后，点击导航栏「我的猫咪」
2. 点击「添加新猫咪」按钮
3. 填写必填信息：
   - 名字
   - 性别（公猫/母猫）
   - 出生日期
4. 可选填写：品种、领养日期、体重等信息
5. 点击「创建档案」

### 切换当前猫咪

在多个页面顶部都有猫咪选择器：

- **AI医师页面**：选择要咨询的猫咪
- **养成时间线页面**：查看指定猫咪的记录
- **疫苗管理页面**：管理指定猫咪的疫苗

点击选择器 → 选择猫咪 → 全局状态更新

### 添加疫苗记录

1. 进入「我的猫咪」→ 选择猫咪 → 点击「疫苗记录」
2. 点击「添加疫苗」
3. 填写疫苗信息：
   - 疫苗名称（选择或自定义）
   - 接种日期
   - 下次接种日期（可选）
   - 医生和诊所（可选）
4. 保存后自动显示在疫苗时间线

### AI咨询流程

1. 确保已选择要咨询的猫咪
2. 在AI医师页面，顶部会显示当前猫咪信息
3. 输入问题，AI会自动：
   - 获取猫咪档案
   - 检索相关知识库
   - 结合猫咪情况给出建议
4. 对话记录会自动关联到当前猫咪

## 数据模型

### Cat（猫咪档案）

```typescript
interface Cat {
  id: string
  userId: string

  // 基本信息
  name: string           // 猫咪名字
  avatar?: string        // 头像URL
  breed?: string         // 品种（如：英短、美短、布偶等）
  gender: string         // "male" | "female" | "unknown"
  birthDate: Date        // 出生日期
  adoptDate?: Date       // 领养日期

  // 健康信息
  weight?: number        // 当前体重(kg)
  isNeutered: boolean    // 是否绝育
  neuteredDate?: Date    // 绝育日期

  // 特殊标记
  color?: string         // 毛色
  features?: string      // 特征描述
  allergies?: string     // 过敏信息
  diseases?: string      // 既往病史

  isActive: boolean      // 是否活跃（软删除）
  createdAt: Date
  updatedAt: Date
}
```

### VaccineRecord（疫苗记录）

```typescript
interface VaccineRecord {
  id: string
  catId: string

  // 疫苗信息
  vaccineName: string    // 疫苗名称
  vaccineType: string    // 疫苗类型分类
  manufacturer?: string  // 生产厂家
  batchNumber?: string   // 批号

  // 接种信息
  vaccinatedAt: Date     // 接种日期
  nextDueDate?: Date     // 下次接种日期
  veterinarian?: string  // 接种医生
  clinic?: string        // 接种诊所

  // 反应记录
  reaction?: string      // 接种后反应
  notes?: string         // 备注

  createdAt: Date
  updatedAt: Date
}
```

### PetRecord（成长记录）

```typescript
interface PetRecord {
  id: string
  userId: string
  catId: string          // 新增：关联到具体猫咪

  recordDate: Date       // 记录日期
  weight?: number        // 体重(kg)
  height?: number        // 身高(cm)
  mood?: string          // 情绪状态
  activity?: string      // 活动情况
  food?: string          // 饮食情况
  notes?: string         // 备注
  photos?: string        // 照片URL

  createdAt: Date
  updatedAt: Date
}
```

### 认证

所有需要登录的API都需要在请求头中携带JWT Token：

```
Authorization: Bearer <your_token>
```

### 猫咪管理 API

#### 获取猫咪列表

```http
GET /api/cats
Authorization: Bearer <token>
```

**响应**：
```json

  "success": true,
  "message": "获取猫咪列表成功",
  "data": [

      "id": "cm3abc123",

      "breed": "英短",
      "gender": "male",
      "birthDate": "2023-11-15T00:00:00.000Z",
      "weight": 5.2,
      "isNeutered": true,
      "ageFormatted": "2岁3个月",
      "avatar": null
    }
  ]

```

#### 创建猫咪档案

```http
POST /api/cats
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "小白",
  "gender": "female",
  "birthDate": "2024-03-01",
  "breed": "布偶",
  "weight": 3.5,
  "isNeutered": false
```

#### 更新猫咪档案

```http
PUT /api/cats/:id
Authorization: Bearer <token>
Content-Type: application/json

{
  "weight": 5.5,
  "isNeutered": true,
  "neuteredDate": "2025-06-01"
}
```

#### 删除猫咪档案

```http
DELETE /api/cats/:id
Authorization: Bearer <token>
```

## 常见问题

### Q: 一只猫的记录会影响其他猫吗？

A: 不会。每只猫咪有独立的成长记录、疫苗记录和对话历史，互不干扰。

### Q: 删除猫咪后，相关数据怎么处理？

A: 删除猫咪采用"软删除"方式，猫咪标记为非活跃状态，但历史数据保留。如需彻底删除，请联系客服。

### Q: AI 如何知道我咨询的是哪只猫？

A: 在AI医师页面顶部有猫咪选择器，选择后AI会自动获取该猫咪的档案信息。

### Q: 疫苗提醒什么时候触发？

A: 系统会在疫苗到期前30天进行提醒，在疫苗管理页面可以看到"即将到期"的疫苗列表。

### Q: 可以导出我的猫咪数据吗？

A: 目前暂不支持导出功能，未来版本会考虑添加数据导出功能。
